# Серверный поиск после 0.2.2

Проверено 24 октября 2026. Сервер не развёрнут, аккаунты/биллинг не подключены. Локальные результаты остаются основными. GitHub Pages серверные функции не выполняет.

| Вариант | Бесплатные условия | Россия и ограничения |
| --- | --- | --- |
| Yandex Cloud Functions, регион Россия | Ежемесячно 1 млн вызовов, 10 ГБ×час и первые 100 ГБ исходящего трафика без тарификации. Это free tier, не только пробный грант. | Основной кандидат для проверки пользователями РФ. Нужны аккаунт/биллинг; превышение оплачивается. Логи, очередь, хранилище и API Gateway тарифицируются отдельно. Нужен ограничитель расходов. |
| Vercel Functions, Hobby | Бесплатный тариф для личных некоммерческих проектов; квоты и остановка функций после исчерпания. | Доступность конкретного домена из РФ не подтверждена. Для коммерческого проекта Hobby не подходит. Не использовать как публичный универсальный proxy. |

Источники: [Yandex pricing](https://yandex.cloud/ru/docs/functions/pricing), [free tier](https://yandex.cloud/en/docs/billing/concepts/serverless-free-tier), [Vercel Hobby](https://vercel.com/docs/plans/hobby), [fair use](https://vercel.com/docs/limits/fair-use-guidelines). Бесплатные квоты не отменяют лимиты Shikimori.

Cloudflare **не обязательная зависимость**. Сам провайдер [26 июня 2025 сообщил о замедлении из РФ](https://blog.cloudflare.com/russian-internet-users-are-unable-to-access-the-open-internet/). Это свидетельство риска, не замер всех российских сетей сегодня. В этой среде нет подтверждённой точки проверки в РФ: нельзя гарантировать доступность Yandex/Vercel/Pages/Shikimori всем российским пользователям. Перед выбором нужны проверки без VPN в мобильной и фиксированной сети РФ: DNS/TLS, JSON больше 16 КБ, задержки/ошибки и доступ к upstream из выбранного региона. Собственный домен не гарантирует устранение сетевых проблем.

## Контракт реализации

- Зарегистрированное OAuth2-приложение Shikimori, серверный User-Agent с его именем; согласованные условия и трафик. Секреты не публиковать.
- Только `GET /search?q=...` и `GET /anime/:id`. Фиксированный GraphQL к проверенному HTTPS origin, никаких произвольных URL/query. Проверять числовой ID, строку 2–100 символов, схему и размер ответа; исключать adult-контент.
- Общая очередь/лимитер приложения, а не независимые счётчики serverless-инстансов. ≤1 upstream-запрос/с и ≤60/мин с учётом повторов/импорта. Объединять одинаковые запросы, кешировать поиск 15 минут/детали 24 часа. Координация требует отдельного хранилища или одного процесса: учитывать его цену/квоты.
- Allowlist Origin сайта, общий/IP лимит, timeout, Retry-After, circuit breaker. CORS не защищает от злоупотребления вне браузера. Дебаунс 400 мс, минимум 2 символа, AbortController, до 10 результатов.
- Сначала локальные результаты, отдельно «Дополнительно из Shikimori», видимые загрузка/ошибка. Отказ сервера не ломает локальный поиск. Постеры только через реестр прав.
- До включения внешних результатов реализовать полноценную статическую оболочку `/external/?id=123`: валидация ID, загрузка деталей через backend, реальные поля/пропуски, источник, состояния 404/timeout. Локальные ID ведут на существующие `/anime/slug/`.
- Build остаётся offline. На опубликованном AniRezik проверить настоящий Origin/CSP, UA на upstream, CORS, 403/429/5xx/timeout/offline, внешний ID без локальной страницы и доступность из РФ. Никаких открытых CORS-прокси.
