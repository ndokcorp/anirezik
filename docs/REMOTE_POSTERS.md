# Удалённые постеры — 0.3.2

## Локальный просмотр

Запустите `npm run dev:posters`, откройте `http://127.0.0.1:4321/`. Это тот же AniRezik с настоящими URL постеров из текущего снимка, без изменения дизайна. Обычный `npm run dev` оставляет публичную политику. Флаг `ANIREZIK_EXPERIMENTAL_SHIKIMORI_POSTERS=1` задаётся только дочернему процессу; `.env` изменять не требуется.

Эксперимент разрешён только при `import.meta.env.DEV`, явном флаге и отсутствии CI. Middleware отклоняет не-loopback hostname. Production build игнорирует переключатель даже при значении 1; workflow дополнительно фиксирует 0. Не размещайте dev-сервер за публичным прокси. Пометка `local-experiment` не является разрешением на публикацию и никогда не записывается в реестр как `permission-granted`.

## Автоматический источник

`queries.ts` запрашивает `poster.mainUrl` и `poster.originalUrl`, `mapper.ts` сохраняет точные HTTPS строки в `sourcePosterMainUrl` и `sourcePosterUrl`. URL, включая хеш/имя файла, не собираются вручную. Обновляет их обычный sync с существующими кешем/ограничениями/атомарным снимком; отображение карточек не обращается к GraphQL. Повторный импорт 30 704 аниме для этой версии не выполнялся.

`image-policy.ts` проверяет HTTPS origin и отсутствие credentials. Карточки используют mainUrl, подробная страница — originalUrl, если он есть. Отсутствующий mainUrl заменяется доступным originalUrl и наоборот. При отсутствии обоих остаётся прежняя разрешённая иллюстрация или заглушка.

`image-index.json` v2 содержит небольшие разрешённые изображения, флаг пакетов и список доступных диапазонов. `/data/images/BUCKET.json` содержит только разрешённые/локально экспериментальные записи ID/1000. Фильтры и избранное создают карточки с заглушкой и запрашивают пакеты только у экрана (160 px); поиск запрашивает максимум 6 результатов, детали — один пакет. Общая очередь ограничена тремя запросами; успешные пакеты переиспользуются в документе. Полные исходные данные и тысячи URL не встраиваются в каждый HTML и не скачиваются до необходимости.

`RemotePoster`/клиентский эквивалент: обычный `img`, размеры 400×600, `object-fit:cover`, lazy/async, без crossorigin. Карточки раскрывают src у экрана через IntersectionObserver; их изображения не загружаются тысячами. Ошибка даёт один переход на нейтральную заглушку, затем скрытие при отказе самой заглушки. Файлы не копируются в assets. Кеширует браузер согласно настоящим HTTP-заголовкам источника; Service Worker, прокси и cache-buster не добавлены.

Широкий фон независим: существующий разрешённый backdrop сохраняется, иначе используются CSS blur/затемнение/градиент из разрешённого или локально тестируемого компактного постера. Он не объявляется новым горизонтальным артом. Прямой originalUrl загружается только для открытой страницы деталей.

## Включение после согласования

Индивидуальный `src/data/image-rights.json` сохранён. Дополнительно `src/data/image-sources.json` описывает источник и scope; сейчас Shikimori имеет `status:unknown`, пустое evidence и неподтверждённые условия.

Для публичной некоммерческой беты нужны документальные условия, явно покрывающие требуемые постеры и право встраивания в сторонний каталог, браузерный кеш, атрибуцию и охват записей. Разрешение доступа к API само по себе недостаточно. Коммерческая эксплуатация требует отдельного подтверждения. Администрации подготовлен [неотправленный запрос](SHIKIMORI_REQUEST.md).

После получения подходящего подтверждения владелец указывает реальное evidence, атрибуцию и точные origins, ставит `hotlinking:true`, `browserCaching:true`, `status:permission-granted`. Обязательно задать scope.kind: all только при подтверждении всего источника, ids + animeIds для перечисленных аниме либо urls + urls для точных файлов. По умолчанию none. expiresAt ограничивает срок при сборке; истечение/отзыв уже опубликованных прав требует своевременной пересборки. Затем rebuild автоматически разрешает только охваченные main/original URL. Новый хеш не наследует разрешение на конкретный старый URL. Ручная загрузка тысяч изображений и платный API не требуются. Не следует выдавать разрешение на несколько файлов за разрешение на весь источник.

## Архив измерения 0.3.1

Команда `npm run test:posters:live` запускается отдельно при работающем локальном эксперименте. Обычные unit/Playwright тесты остаются воспроизводимыми без внешней сети и используют собственные fixtures.

[Отчёт CDN-проверки](research/remote-posters-local.json): **30/30 настоящих mainUrl** декодировались в Chromium: 10 популярных, 10 старых, 5 редких CM/PV/music, 5 фильмов. Свежий browser context, до трёх изображений параллельно. Общая фаза пакетов/декодирования — **1525 мс**, отдельные изображения **77–446 мс**, медиана **96 мс**. После перехода на другой документ те же **30/30** снова декодировались, CDP зарегистрировал **30 событий обслуживания из кеша**. ResponseReceived в CDP приходит и для кеша, поэтому 30 записей повторных responses не считаются 30 сетевыми скачиваниями. Наблюдаемый CDN Cache-Control: `max-age=315360000, public`; это техническое поведение, не лицензия.

Качественный оригинал редкого ID 3929 декодировался через реальную универсальную страницу: **600×453**. API-запросов за весь сценарий — **0**. В медленной мобильной эмуляции (390×844, CPU ×4, 400 мс, 50 000 байт/с) отдельная свежая выборка из шести постеров дала **6/6**, **5727 мс**, **152 628 байт**, отдельные decode **512–1332 мс**. Это время тестовой выборки, не время всей главной и не замер физического телефона/российской сети.

Все результаты относятся к локальному эксперименту. Успех декодирования не подтверждает публичные права; в GitHub Pages настоящий источник остаётся отключён до согласования.
