# Мобильные правки AniRezik 0.4.4

Поиск: короткое «Загрузка…», прозрачный внешний dialog без вложенной круглой панели. Поисковая строка и отдельная круглая кнопка закрытия находятся в одном верхнем ряду. visualViewport.height/offsetTop и события resize/scroll удерживают окно внутри видимой области при клавиатуре; результаты прокручиваются отдельно. При закрытии слушатели снимаются и фокус возвращается открывшей кнопке. Размер полей ≥16px, pinch zoom сохранён. Аппаратные iPhone/Android не подключены: проверяется воспроизведение изменения visual viewport в браузере, а не заявляется физическая проверка клавиатуры.

Коллекция: одна кнопка «Фильтр» с текущей категорией вместо ряда вкладок. Пять вариантов — избранное и прежние четыре статуса; выбранный URL list сохраняется при перезагрузке. Автообновление при выборе и событиях существующих хранилищ. Пустой текст и постоянная кнопка обновления убраны только из коллекции; счётчик, ошибки загрузки, удаление и «Показать ещё» сохранены. История по-прежнему отдельно доступна в меню и футере.

Меню под постером: четыре прежних статуса, контрастные SVG слева, текст по центру. Общая library-menu управляет анимацией с отменой при быстром повторном открытии, outside click, Escape, стрелками/Home/End и reduced motion. Закрывающееся меню inert, чтобы не принимать повторный случайный выбор.

При открытии мышью фокус явно ставится на кнопку: Safari не обязан фокусировать button при pointer click. Это сохраняет Escape после повторного открытия; клавиатурное открытие направляет фокус в меню.

Дублирующие история/коллекция удалены из угла шапки; мобильная кнопка меню имеет цель 44×44px. Основной постер сохранён; повторное изображение в баннере удалено, нейтральная полоса компактнее и отступает от шапки. Рейтинг на верхнем левом углу основного постера, без выдумывания отсутствующей оценки. Эти изменения применены и к SSR, и к универсальному detail.

Убрана поясняющая строка хронологии, скорректирован отступ трека. Подзаголовок похожих: «Схожие аниме по жанрам в каталоге». Подписи источников под аниме-плеером скрываются по умолчанию; обязательная атрибуция остаётся через явный attributionRequired (включён для CC BY тестового материала). AniLiberty/Kodik, реклама, воспроизведение и ID не изменены.

Правки отделены от локальной ветки Kodik 0.4.5: её API-клиент, конфигурация и workflow не входят в эту публикацию. Каталог, постеры и описания повторно не импортируются. Проверки используют прежние offline fixtures, без повторного длительного видео.

Локальная проверка: npm run check — 0 ошибок/предупреждений; офлайн build — 3020 страниц. На base / прошли 11 целевых Chromium-сценариев, на production /anirezik/ — 13, включая быстрый повтор открытия во время анимации, пустые/непустые списки, поиск с изменением visual viewport, обе detail-схемы и сохранённый MultiPlayer. Визуально проверены 375×812 и 1366×768, реальные постеры декодировались. Фото QA — только в игнорируемой .cache/mobile-polish. Перед Pages остаётся штатная общая матрица Chromium/Firefox/WebKit.
