# Работа с каталогом

Источник фактических данных — `src/data/catalog.json`, автоматически формируемый `npm run sync:anime`. Не заменять его демонстрационными объектами и не вписывать оценки/даты вручную. Файл коммитится вместе с исходниками: сборка GitHub Pages не требует API.

Конкретное аниме: `npm run sync:anime -- --ids=1,5114`. Команда объединит перечисленные ID с основными подборками, уберёт повторы и сохранит уже опубликованные записи. Для первых 16 тайтлов соответствие ID/slug задано в `providers/shikimori/legacy.ts`; новые URL имеют вид `anime/shikimori-<id>/`. Название может меняться, ID и URL — нет.

Собственные описания и редакционные поисковые алиасы — `src/data/editorial.json`, ключом служит Shikimori ID. Описания подписываются как текст редакции. Новое редакционное описание попадёт в snapshot при следующем sync. Нельзя автоматически копировать тексты с сайта без соответствующих прав. Если своего текста нет, показывается понятное сообщение и ссылка на источник.

Рейтинг пользователей и возрастной рейтинг — разные поля. Планируемые и вышедшие эпизоды не означают доступные на AniRezik видео. Не исправлять спорные числа «по логике»: Shikimori может обновляться с задержкой. Часть дат имеет только год/месяц; не дописывать вымышленный день. Студии анимации не являются студиями озвучки.

Постеры сейчас нейтральные. Чтобы перейти на реальные изображения, сначала документировать право на конкретный набор материалов, разрешённый способ доставки, атрибуцию и ограничения. После этого реализовать отдельную политику изображений и проверить её тестами. Публичная sourcePosterUrl сама по себе не даёт разрешения. Существующие AI-обложки сохранены в assets для истории, в прототипе карточки используют их через реестр разрешений с подписью AI. Декоративные hero-иллюстрации подписаны и не выдаются за официальные постеры.

Редакционные ID главной заданы явно; «Популярное» не утверждает измеренную посещаемость. Новинки соответствуют сезону формирования снимка, онгоинги — статусу источника. Рекомендации на подробной странице основаны на общих жанрах, не на скрытом рекомендательном API.

После изменения: `npm run check`, `npm run build`, `npm test`. При изменениях путей проверить `/` и `/anirezik/`. Восстановление после неудачного импорта — SHIKIMORI.md; результаты — VALIDATION.md.


## Обновление 0.2.1

Текущий каталог: 1000 записей. Поисковый индекс вынесен в единый search-index.json, импорт расширен до 1000 с настройкой --target=3000 и возобновлением из кеша пакетов. Изображения выбираются отдельным реестром image-rights.json: 16 оригинальных иллюстраций прототипа подписаны как AI, чужие постеры не включаются автоматически. Один существующий широкий hero.webp подключён также на подробную страницу; для 15 других исходных тайтлов фон размыт из разрешённой иллюстрации. Для остальных баннер нейтральный, без большой буквы A. Подробности: [SEARCH.md](./SEARCH.md), [IMAGES.md](./IMAGES.md).
