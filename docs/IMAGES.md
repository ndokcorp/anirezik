# Изображения AniRezik 0.3.3

20 сериалов используют TVmaze, 40 точных medium/original URL в ограниченном реестре, CC BY-SA 4.0 с атрибуцией и ссылками. `remotePoster` в image-rights.json не заменяет исходные AI записи: при unknown/отзыве источника они возвращаются. Выбор выполняет существующий image-policy; загрузчик/IntersectionObserver/размеры/fallback прежние. Подробные первичные основания — [POSTER_RIGHTS.md](POSTER_RIGHTS.md). Shikimori production по-прежнему выключен. Исходные 16 AI сохранены, 3 остаются основными изображениями. Историческое описание ниже относится к прежнему состоянию.

## История 0.3.1

Добавлен отдельный локальный эксперимент: `npm run dev:posters`. В нём реальные постеры Shikimori автоматически берутся из сохранённых main/original URL; **30/30** настоящих файлов декодированы в браузере, повтор использовал кеш, API-запросов 0. Публичный источник остаётся unknown и выключен. [Текущий механизм, включение после согласования, измерения](REMOTE_POSTERS.md). Данные изображений разделены на небольшой image-index v2 и пакеты диапазонов; детали используют оригинал. Production и CI не принимают локальный переключатель.

## Состояние до локального эксперимента (0.3.0)

Пользователь подтвердил отсутствие разрешений. Реальные внешние постеры Shikimori/TMDB **не включены**. 28 757 из 30 704 записей содержат poster.mainUrl/originalUrl в настоящих ответах API; это подтверждение наличия URL, не лицензии/декодирования/допустимости hotlink. Массив URL не скачивается браузером.

Сохранены 16 исходных AI-иллюстраций с подписями, один собственный широкий hero и нейтральные SVG-заглушки. Новые тысячи замен не генерировались, public/assets не пополнялся постерами. Коммерческие права на персонажей не утверждаются.

## Реализованный тракт

- RemotePoster.astro — обычный img с HTTPS либо разрешённым local asset, width=400/height=600, loading=lazy, decoding=async, object-fit:cover; crossorigin не устанавливается.
- Старый Poster переиспользует RemotePoster. Карточки, созданные браузером, используют эквивалентный helper и общий image-client.
- Ошибка заменяет src один раз на нейтральный SVG; при ошибке самого fallback изображение скрывается. Обработчики привязываются один раз, бесконечных повторов нет. Проверяются и уже произошедшие ошибки/naturalWidth.
- image-rights.json остаётся единственным ручным реестром. unknown/пустые evidence/атрибуция не включаются. Исходные sourcePosterMainUrl/sourcePosterUrl не активируют img.
- Изображения поставляются отдельно через image-index.json, только для разрешённых ID. Поля: posterUrl, backdropUrl, imageSource, imageAttribution, imageLicenseStatus. bannerUrl — сохранённый совместимый алиас backdrop. HTTPS проходит imageUrl без ошибочного добавления base path; это исправлено также в hero.
- После подтверждения прав добавить точный источник, файл/URL, атрибуцию, статус permission-granted и документальные условия в evidence. Не подменять unknown на granted ради картинки.

## Широкий фон

Широкий backdrop независим от вертикального постера. При разрешённом широком изображении показывается оно. При наличии только разрешённого постера — CSS blur + затемнение, явно не полноценный новый широкий арт. Если нет разрешённого изображения — нейтральный градиент. Изображения не растягиваются как чёткие пиксельные «баннеры»; фон из постера намеренно размыт. Ошибка фона скрывает img и оставляет градиент. Подпись источника/лицензии сохраняется.

## Проверки и границы

В каждом доступном браузере тестируются **30 собственных SVG fixtures** по тестовым HTTPS URL: настоящее декодирование img, размеры, lazy/async, отсутствие crossorigin, однократный fallback после abort. URL перехватывает тестовый route, данные SVG принадлежат тестам. Это техническая проверка 30 изображений, **не 30 внешних аниме-постеров и не подтверждение чужих прав/реального CDN**.

Также сохранён тест реального запроса оригинального WebP с abort, декодированием SVG fallback и отказом широкого hero. Успешно проверенных опубликованных внешних аниме-постеров — **0**, подключённых — **0**. Вопрос прав не называется технической ошибкой. Для воспроизводимой проверки 30 настоящих постеров нужны разрешённый источник/подтверждение, список URL/ID и при необходимости API account/key.

[Исследование лицензий/hotlink/cache/атрибуции/коммерции](POSTER_RIGHTS.md), [неотправленный запрос администрации](SHIKIMORI_REQUEST.md). API Shikimori, TMDB FAQ/terms и AniList terms проверены; отсутствие запрета не считается разрешением. TMDB требует принятия условий/ключа и атрибуции, коммерция — отдельного договора; универсальная лицензия на каждый сторонний арт не подтверждена.

Дополнение по загрузке: изображения карточек раскрываются через IntersectionObserver только рядом с экраном (160 px), скрытые слайды hero загружаются при выборе. Неиспользуемый поисковый Worker завершается через 60 секунд, повторный поиск использует HTTP-кеш индекса. При замене карточек старые наблюдатели освобождаются.

Проверка широких источников: официальный [TMDB TV images endpoint](https://developer.themoviedb.org/reference/tv-series-images) отдельно возвращает backdrops/posters/logos; [image basics](https://developer.themoviedb.org/docs/image-basics) описывает URL через configuration/base_url/file_size/file_path. То есть широкие файлы технически предусмотрены, но API требует credentials и условий использования. Без аккаунта/ключа и подтверждённых прав проекта реальные backdrops не получались и не включались; документация метода не считается разрешением на любой файл.
