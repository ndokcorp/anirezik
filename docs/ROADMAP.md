# Дальнейшее развитие после 0.3.0

1. Получить документальные разрешения на реальные постеры/широкий арт и условия hotlink/cache/атрибуции/коммерции. Подключить конкретные разрешённые URL в image-rights.json, затем проверить не менее 30 настоящих файлов в браузерах. Технические SVG fixtures не заменяют этот шаг.
2. Зарегистрировать приложение Shikimori, настроить User-Agent, репозиторий/Pages и автоматизацию через проверяемый PR. Периодически выполнять полный обход/сверку; ограниченное обслуживание не объявлять полным обновлением всех записей.
3. Проверить производительность/доступность на физических слабых телефонах и в мобильных/фиксированных сетях РФ без VPN. Измерения headless Chromium и CPU/network throttling не являются проверкой реальных устройств.
4. При дальнейшем росте/медленном холодном поиске исследовать шардирование индекса по нормализованным токенам или дополнительный компактный inverted index. Сейчас сжатый индекс 2.34 МБ, Worker не блокирует основной поток, но первое скачивание не мгновенное.
5. Для live-поиска новых записей между сборками нужен согласованный backend с общими лимитами/кешем; полный локальный индекс и универсальные JSON-страницы уже работают без сервера. Cloudflare не обязателен; варианты/риски РФ в GLOBAL_SEARCH.md.
6. Подтвердить конкретных видеопровайдеров, права/регионы, затем реализовать адаптер. Сейчас активных источников нет. Аккаунты, живой календарь и серверная синхронизация остаются отдельными задачами.
7. Коммерческий режим требует отдельной проверки лицензий и условий хостинга; бесплатная некоммерческая бета не создаёт коммерческих разрешений.
