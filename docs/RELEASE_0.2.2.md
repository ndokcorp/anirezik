# AniRezik 0.2.2 — отчёт

Дизайн, логотип, Astro, существующие компоненты/страницы и избранное сохранены. Репозиторий/публикация не создавались.

1. **Каталог:** 3000 уникальных аниме, +2000. Все первоначальные 1000 ID и их страницы сохранены. Импорт: 65 пакетов, 40 новых запросов, 25 кешированных; очередь, Retry-After, дедупликация, атомарная запись/резервная копия и продолжение из кеша сохранены. По умолчанию 3000, явно можно до 5000; выполненного импорта 5000 не заявляем.
2. **Поиск:** только локальный. Индекс один на сайт, заранее нормализуется в памяти; точные названия/алиасы приоритетны. CORS из настоящего HTTPS GitHub Pages работает в Chromium/WebKit, но Chromium игнорирует User-Agent приложения. [Методика и отчёт](SEARCH.md). Глобальная интеграция, не соответствующая требованиям API, не включена.
3. **Постеры:** настоящие сторонние постеры не подключены, универсальное разрешение не подтверждено. Сохранены 16 подписанных исходных AI-иллюстраций и нейтральные заглушки. [Правовое исследование](POSTER_RIGHTS.md) отделяет показ, embedding, кеш, атрибуцию и коммерческие права; [конкретный запрос](SHIKIMORI_REQUEST.md) подготовлен, не отправлен. Реестр разрешений не заполнен неподтверждёнными URL.
4. **Ограничения:** нет подтверждённого имени зарегистрированного приложения/серверного поиска, разрешений на сторонние изображения/описания, проверенной доступности из РФ и подключённого репозитория Pages. HTML каталога/избранного содержит все карточки (~4.8 МБ каждый), что ограничивает дальнейшее масштабирование. Firefox блокируется средой Windows до навигации.
5. **Файлы:** полный список ниже. Код поиска, фильтрации и генерации оптимизирован; исправлена потеря раннего клика избранного, ожидавшего индекс. Главная показывает шесть фильмов вместо 622 и ведёт в полный каталог.
6. **Проверки:** check и build успешны; 3008 страниц, 79.16 МиБ при `/`, 80.89 МиБ при `/anirezik/`, локальные сборки 24–26 с. Unit/Chromium/WebKit: **56/56 на / и 56/56 на /anirezik/**. Покрыты поиск вне исходной тысячи, прежние страницы/избранное, отказы API и загрузки изображений. Результаты и границы проверки — [VALIDATION.md](VALIDATION.md). Тесты Firefox сохранены, успешная проверка Firefox не заявляется.
7. **Следующая версия:** зарегистрировать приложение и согласовать права; выбрать backend с общей очередью/кешем и практической проверкой из сетей РФ; сделать полноценную `/external/?id=...` страницу до включения внешних результатов; добавить порционную загрузку карточек и измерения на реальных телефонах. Бесплатные варианты: [GLOBAL_SEARCH.md](GLOBAL_SEARCH.md); Cloudflare не обязателен. Для коммерческого режима отдельно проверить лицензии и условия хостинга.
