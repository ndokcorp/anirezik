# Обновления доступности 0.3.2

Новый контракт `providers/video/updates.ts`: собственный cursor и дельта VideoSource, проверка прав/origins/региона, сохранение прежних серий при частичном ответе, отсутствие изменений при отказе. Ни один адаптер не включён. episodesAired Shikimori, доступность видео и dubbingStudio остаются разными данными. [Подробности и ограничения](SMART_SYNC.md).

# Подключение видеопровайдеров

В 0.2.0 список `approvedProviders` пуст. Нет официально подключённых потоков, iframe или озвучек. Названия AniLiberty/AniLibria, AniDUB и Студийная Банда не означают разрешения или наличия интеграции.

Контракт `src/lib/providers/video/types.ts` отделяет студию анимации из метаданных от `dubbingStudio` звуковой дорожки. Каждый VideoSource содержит animeId, номер эпизода, идентичность провайдера, язык, студию озвучки, языки субтитров, embed/playback URL, регионы и атрибуцию.

Для провайдера нужны документированное разрешение, URL условий, дата проверки, отдельные флаги embeddingAllowed/playbackAllowed и точные HTTPS origins. `getVideoSources` допускает только соответствующие разрешениям URL, положительные номера эпизодов и доступный регион. `*` означает документированную мировую доступность. Если источник ограничен по регионам, а регион неизвестен, он не включается. Региональная проверка интерфейса не заменяет требования провайдера и его собственную проверку доступа.

`AnimePlayer`, `EpisodeSelector`, `DubSelector` отображаются как плеер только при наличии проверенных вариантов. Переключаются фактически доступные эпизоды/языки; пустые источники не превращаются в ложные кнопки просмотра. Iframe использует sandbox и не запускается автоматически. Нужно дополнительно проверить разрешённые sandbox/allow директивы по документации конкретного провайдера, CSP/frame-ancestors/X-Frame-Options, DRM, региональные условия и правила рекламы. Если iframe не разрешён, сохранить официальную внешнюю ссылку, не обходить ограничение.

Перед включением интеграции: добавить адаптер, подтвердить права для конкретных произведений/регионов, протестировать выбор серии/озвучки, сбои и доступность, обновить CSP для известных доменов на хостинге. Текущая реализация не утверждает, что разрешения уже получены. Доступные будущие источники с субтитрами должны предоставлять отдельные данные дорожек; массив subtitles сейчас перечисляет языки, а не URL файлов субтитров.
