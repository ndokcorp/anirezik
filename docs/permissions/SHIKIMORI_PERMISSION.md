## Фактический объём и реализация

- Бесплатное публичное размещение постеров на названном AniRezik по URL из API. В сообщении нет ограничения отдельными тайтлами; применяется ко всем сохранённым подходящим API URL постеров.
- Прямой img с HTTPS origin `https://shikimori.io` реализует разрешённое размещение по URL. Слово hotlinking отдельно не употреблено; `hotlinking:true` обозначает именно эту интерпретацию способа доставки, не безлимитную нагрузку.
- `browserCaching:null`: отдельное согласие на хранение файлов не заявляется. `browserCachePolicy:http-response-headers` разрешает только обычный кеш браузера, управляемый Cache-Control/Expires/ETag источника. Нет своего хранилища/CDN, service worker-кеша постеров, прокси или массового скачивания. Обязательный ранее флаг blanket cache permission отделён от этого стандартного HTTP-поведения, а не заполнен вымышленным разрешением.
- Карточки используют точный mainUrl, детали — originalUrl; без изменения URL/имён файлов. Атрибуция Shikimori сохранена добровольно, специальных требований в ответе нет.
- `expiresAt:null` означает «срок не указан», а не бессрочную гарантию. Коммерческое использование, перепродажа, собственный CDN/хранилище, произвольные производные файлы, неограниченный трафик и гарантии прав третьих лиц не подтверждены.
