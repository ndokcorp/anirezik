# Описания 0.3.6

23 доступных ID: 16 редакционных текстов из editorial.json и 7 дополнительных английских описаний TVmaze. Для 20 уже сопоставленных сериалов сохранены разрешённые TVmaze summaries; если есть свой редакционный текст, он имеет приоритет. Сборка не обращается к API: использованы уже кешированные ответы предыдущего сопоставления, без повторного импорта каталога и без новых сетевых запросов.

Первичное основание TVmaze: [официальная API license](https://www.tvmaze.com/api#licensing), [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Каждая запись содержит URL конкретного сериала, источник, язык, лицензию и описание изменений. Удалено HTML-форматирование, текст/язык не изменены. Отдельные JSON и изменения форматирования доступны на тех же условиях ShareAlike; исходные редакционные тексты не объявляются текстами TVmaze. Подпись/ссылка/лицензия видны рядом с описанием. Записи и свидетельство: licensed-descriptions.json, description-sources.json. Выключение источника исключает его тексты из сборки.

Полные тексты отсутствуют в search-index и JSON пакетов карточек. Build-time descriptions.ts создаёт `/data/descriptions/ID.json` только для доступных текстов. Общий `/data/anime/ID.json` сообщает hasDescription; неизвестные ID не вызывают лишних 404. Универсальная страница получает метаданные/постер, затем один JSON своего описания; static detail использует такой же loader для дополнительных текстов, редакционный SSR остаётся для SEO. Главная, каталог, поиск и избранное описания не скачивают. Promise-кеш устраняет дубли, timeout/ошибка/пустая или неверная схема сохраняют fallback. Текст вставляется через textContent, source URL ограничен TVmaze, ссылка лицензии проверяется; HTML из API не исполняется.

**Shikimori:** доступность description в API не подтверждает право повторной публикации. [Предоставленная переписка](permissions/SHIKIMORI_PERMISSION.md) касается постеров, а [условия Shikimori](https://shikimori.io/terms) не дали отдельного общего разрешения на сторонние описания. Статус источника текстов unknown, данные не копировались. Для расширения нужны подтверждение охвата текстов и затем адресный импорт с зарегистрированным User-Agent. На страницах без разрешённого описания остаются нейтральное сообщение и ссылка на Shikimori. Это ограничение прав/данных, а не замаскированная ошибка загрузки.
