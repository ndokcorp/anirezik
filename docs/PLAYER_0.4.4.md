# AniRezik 0.4.4 — Player & UI Polish

## Поведение и оформление

Официальный iframe появляется автоматически через IntersectionObserver, когда поверхность просмотра приближается на 320 px к экрану. Нет кнопки «Открыть плеер источника». До этого показан компактный skeleton той же геометрии. Документ iframe загружается, а воспроизведение со звуком без пользовательского действия не разрешается: autoplay отсутствует в URL и запрещён стандартной iframe Permissions Policy. Это не блокировка рекламных запросов; реклама и внутренний интерфейс остаются у поставщика.

Нативная ошибка iframe и длительное ожидание документа дают сообщение/«Повторить»; при наличии альтернативы есть кнопка выбора резервного источника. Тайм-аут означает только долгое ожидание, а не доказанную недоступность видео. Cross-origin HTTP/ошибки самого видео могут сообщаться только внутри плеера: приложение не читает его DOM и не объявляет load доказательством воспроизведения. Повторный выбор или переход страницы уничтожает старый iframe/наблюдатель/таймер. AniLiberty HLS и его исходные обработчики качества/позиции сохранены.

Источник на ПК ограничен шириной 260 px. Два и более источника используют существующий кастомный select сайта с listbox, клавишами стрелок/Home/End/Enter/Escape, возвращением фокуса и закрытием по внешнему клику. Один источник — компактная плашка. Меню раскрывается в потоке, не поверх рекламы и видео. Нативного синего меню нет.

Рамка общая, iframe внутри без scale и без дополнительных скруглений/фиксированной высоты. Поверхность 16:9; правая колонка 300–340 px и её высота следуют реальному stage через ResizeObserver. Список переводов прокручивается внутри, не создавая пустую высоту stage. На телефоне он расположен снизу и ограничен 280 px прокрутки. Контрастный текст студий, звезда отдельно от выбора перевода, бейдж эпизодов, различие озвучки/субтитров. Внешние дублирующие подписи Kodik удалены; внутренние элементы и реклама не изменены. Обязательная внешняя атрибуция при необходимости задаётся адаптером attributionRequired, ссылка AniLiberty сохранена.

## Запрошенное и подтверждённое состояние Kodik

Принимается реально наблюдавшееся событие kodik_player_current_episode. Проверяются точный origin, contentWindow текущего iframe, типы, сезон, доступная серия и перевод из разрешённого текущего Shikimori mapping. Сообщения другого/старого iframe, неизвестных сезонов/переводов игнорируются. Входящее событие меняет UI без render, замены iframe и повторного запроса. Внешние переключения заменяют iframe на точный разрешённый URL; их целевой выбор выделяется как ожидающий, а не выдаётся за подтверждённый.

Последний подтверждённый эпизод/перевод остаётся выделенным до нового допустимого события. Строка «Последнее подтверждение» явно объясняет смысл; загрузка документа не считается подтверждением серии или видео. В прогрессе добавлено необязательное selectionConfirmed, прежние ключи и миграции сохранены. Позиция AniLiberty хранится отдельно от iframe и не стирается его null-временем.

Переходы 1 → 2 → 5 и перевод AniLibria.TV проверены контролируемыми сообщениями iframe; запросов на событии не добавляется. Живой источник ранее присылал стартовое событие, но не всегда присылал новое сразу после изменения меню. Публичный официальный контракт частоты уведомлений/запроса текущего состояния найти не удалось: [главная Kodik](https://kodikplayer.com/) направляет владельцев сайтов на support@kodikres.com. Причина отсутствующих событий не объявляется установленной; задержка из-за рекламы/готовности видео — только гипотеза. Не отправляются вымышленные getState/getCurrentEpisode команды и не выполняется чтение DOM чужого iframe из приложения. Полная мгновенная синхронизация всех внутренних переключений не обещается; требуется контракт поддержки. Длительный повтор видео не проводился.

## Телефоны и шапка

Навигация: Главная / Каталог / красная круглая лупа / Коллекция / Войти. Центральная кнопка открывает существующий глобальный поиск, перемещая тот же SearchBar в native dialog без дублирования индекса/полей. Работает и в каталоге, где desktop-поле скрыто. Escape/крестик закрывают диалог и возвращают фокус. Верхняя мобильная лупа удалена. Учитывается safe-area-inset-bottom; панели не перекрывают видимый блок просмотра или активные поля/диалог поиска.

Авторизации/регистрации в проекте ещё нет: «Войти» ведёт на честную страницу «Вход пока недоступен», не на имитацию работающего аккаунта. Никакое состояние авторизации не выдумано.

Вычисленный font-size текстовых input/select/textarea на мобильных ≥16 px, компактность достигается padding. Viewport не содержит user-scalable=no или maximum-scale=1. Проверка шрифта и мобильной компоновки выполнена в браузерах; физический iPhone с его клавиатурой не подключался. Не заявляется аппаратная проверка Safari zoom.

Шапка ПК 76 px вместо измеренных 86 px (−11,6%), логотип и четыре раздела сохранены, навигация контрастнее. На время видимого блока просмотра липкая шапка не закрывает iframe. Масштаб сайта не запрещён.

## Покрытие и resolver Kodik

Реально включено **1 аниме: Shikimori 39535**, первый сезон/часть 1 (2021), 11 серий, прежние 15 переводов из подтверждённого меню. Новых iframe/тайтлов не активировано. AniLiberty остаётся резервом и источником других точных соответствий. AniVibe/Alloha/Collaps не активируются этой версией.

Новый kodik-resolver.ts индексирует manual JSON по точному Shikimori ID, кеширует до 200 результатов и отвергает неподтверждённые/неразрешённые записи. Проверяются id, title/originalTitle, год, формат, сезон/часть, даты/путь согласия, ID и отдельные media-ссылки переводов, их метаданные и доступные эпизоды. Дублирующийся media URL под разными переводами отклоняется. Разрешение из kodik-rights.json отдельно перечисляет approvedAnimeIds; запись JSON сама по себе не включает новый источник.

### Как добавить ручное соответствие без backend

1. Получить разрешённые точные embed-ссылки и metadata того же релиза у провайдера. Подтвердить Shikimori ID, originalTitle, год, формат, сезон/часть; не выводить их из равенства числовых ID.
2. Подготовить запись по модели существующего kodik-mappings.json. У переводов обязаны совпадать shikimoriId/season/part/year/format родителя. Указывать реальные availableEpisodes для неполного списка; episodes — количество перечисленных доступных эпизодов.
3. Если внешний параметр episode для этого релиза проверен, записать episodeQueryVerified и episodeNavigationEvidence. Иначе требуются точные episodeUrls для каждого эпизода; hash не вычисляется и URL не угадывается. Не присваивать фильму/OVA фиктивные сезон/часть только ради валидации: сначала получить фактическую модель поставщика.
4. Зафиксировать разрешение в docs/rights/KODIK_PERMISSION.md и после проверки добавить ID в approvedAnimeIds. Непроверенные черновики держать вне активного manifest.
5. Выполнить node scripts/validate-kodik-mappings.ts (также входит в npm run check). Он сравнивает title/originalTitle/year/format/количество с прежним checked-in catalog.json, проверяет сезон/переводы и файл разрешения. Сборка по-прежнему офлайн.

Валидация ловит несогласованные данные, но не может самостоятельно доказать принадлежность чужого hash сезону без подтверждения провайдера. Это остаётся частью ручной проверки, а не автоматическим заявлением правильности. Собственный API/выгрузка и условия доступа ко всему каталогу не получены; массовые запросы/чужие ключи не использовались.

Статические ручные записи не требуют backend. Для масштабного автоматического покрытия нужен одобренный API/экспорт с точными внешними идентификаторами и условиями; все 30 704 тайтла не объявляются доступными. Подготовлен типизированный контракт KodikCatalogLookup, без угадывания endpoint или включённого сетевого клиента. Если будущий ключ приватный, нужен разрешённый backend; возможность публичного ключа/CORS нужно подтвердить у Kodik, а не предполагать.

Проверены размеры 1920×1080, 1366×768, 390×844, 375×812; изображения QA сохранены локально в .cache/player-044. Реальный iframe отображался без Play, повтор длительного воспроизведения не проводился. Автотесты не обращаются к его рекламе/потокам: используются явно обозначенные mock-события.

TypeScript/production build и публикация выполняются существующим workflow. Полный импорт не запускался; GitHub Pages base /anirezik/ сохранён.
