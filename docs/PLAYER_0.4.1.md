# AniRezik Player 0.4.1

## Текущее состояние и согласие

AniLiberty включён по предоставленной пользователем переписке-согласию, где прямо запрашивалось подключение API/плеера к своему аниме-сайту с собственной озвучкой AniLiberty. [Запись основания и границы](rights/ANILIBERTY_PERMISSION.md), машинный реестр `src/data/video-rights.json`. Подлинность личности собеседника независимо не устанавливалась; основание — предоставленный владельцем документ и его прямое поручение. Другие студии, iframe, произвольные видеосайты не включены.

Точные HTTPS origins основного HLS и наблюдённых перенаправлений CDN перечислены в реестре. Wildcard, proxy, переписывание подписей, параметров рекламы и обход геоблокировок не используются. Географическая проверка опирается на `is_blocked_by_geo=false` и `is_blocked_by_copyrights=false` в API-ответе текущей браузерной сессии, а не на вымышленный код страны или `*`. Отказ API/CDN остаётся отказом. Новые неизвестные CDN не активируются автоматически.

## Сопоставление

`shikimori:<id>` остаётся основным ID сайта; releaseId используется только внутри провайдера. `src/data/aniliberty-mappings.json` — компактный офлайн seed из пяти проверенных соответствий:

| Shikimori | AniLiberty | Тайтл | Фактические эпизоды |
|---|---|---|---|
| 52991 | 9542 | Фрирен | 28 |
| 9253 | 8674 | Врата Штейна | 25 |
| 52299 | 9600 | Solo Leveling | 12 |
| 58567 | 9839 | Solo Leveling 2 | 13 |
| 32281 | 6826 | Твоё имя | 1 |

Дополнительно исследованы реальные 40748→8789, 48561→9313 (фильм), 51009→9470. Они оставлены для поиска по запросу; не нужно заранее импортировать весь каталог. Тест проверяет несовместимость первого/второго сезона и фильма/сериала. Данные эпизодов могут отличаться от Shikimori: используется реальный ordinal провайдера, включая дробные спецвыпуски.

Главное доказательство — точный `shikimori.id`. MAL применяется только при явно известной привязке malId к внутреннему ID (в seed сохранены совместно возвращённые официальные поля); равенство всех Shikimori/MAL ID не предполагается. Противоречивый Shikimori ID нельзя перекрыть совпавшим MAL. Несколько разных releaseId с тем же внешним ID требуют ручной проверки.

Если внешнего ID нет, функция strictTitleCandidates одновременно сверяет оригинальное/альтернативное название, год, формат и явно определённый сезон. Такие кандидаты всё равно требуют ручного подтверждения. Отсутствие номера сезона не считается доказательством сезона 1. Имя, первая строка поиска, фильм похожей франшизы, ремейк или OVA не используются вместо точного релиза. Если точного соответствия нет, интерфейс показывает «Релиз пока не найден»; спорное совпадение имеет отдельное сообщение.

## Запросы и кеш

Только официальные API v1: `/app/search/releases?query=…`, `/anime/releases/{id}`. `/anime/releases/list?ids=…` использован один раз для ограниченного исследования восьми тайтлов. Не используется v3, полный импорт Shikimori или поиск по всем 30 704 ID.

Запросы выполняются лишь на detail в браузере: build всегда использует локальный snapshot и не ищет видео. Общая очередь — один запрос, интервал не менее 400 мс, timeout 12 с, дедупликация одинаковых in-flight запросов, ограниченный памятью кеш (32 ответа, 3 минуты). Максимум три поисковые фразы одного тайтла. Положительные exact-ID соответствия сохраняются в отдельный localStorage JSON `anirezik:aniliberty-mappings:v1` на 30 дней (до 500 записей); после перезагрузки поиск не повторяется, но свежая доступность/геофлаги проверяются подробным ответом. Неудавшаяся сеть не записывается как подтверждённое соответствие. Отрицательный кеш в памяти 15 минут. API-ошибка не подставляет случайный поток.

## Интерфейс и воспроизведение

Общий загрузчик используется и Astro detail, и `/anime/?id=…`. Слева увеличенное видео 16:9 с разрешённым постером, названием и красной кнопкой. Справа реальный выбор дорожки и список только фактически доступных серий; навигация предыдущая/следующая синхронизирована. На узком экране панель переносится под видео. Подключена одна реальная озвучка AniLiberty; студии из картинки-примера не имитируются.

HLS.js загружается только после play и предпочтителен при MSE-поддержке: Chromium на этой машине сообщает native HLS=maybe, но не декодирует MPEG-TS надёжно. Если HLS.js/MSE не поддерживается, остаётся native HLS. Отдельные 480/720/1080 берутся только из ответа, Auto не выдумывается. Начальное качество — 720p на desktop и 480p на mobile при наличии. Переключение уничтожает предыдущий HLS/video source и сохраняет позицию; одна video-нода. Сохраняются прежние управление, fullscreen, скорость, громкость, ошибки/повтор и локальный прогресс.

## Проверки

Реальный Solo Leveling: воспроизведение, 480p→720p, продолжение с 00:15 после reload, запуск серии 2, один video, mobile 390 px без переполнения. CDN redirect origins проверены по фактическим ответам и ограниченному HEAD шести первых сегментов (две серии × три качества), видео на GitHub не копируется. Одно прерывание запроса при уничтожении старого HLS при смене источника ожидаемо.

Воспроизводимые CI-тесты используют санитарный fixture API с сохранёнными реальными ID/метаданными и явно тестовыми stream URL; реальную сеть они не вызывают. Проверяются пять exact-ID соответствий, неоднозначность, несмешение сезона/фильма, сохранение mapping и отсутствие повторного поиска после reload, UI эпизодов, оба маршрута и mobile. Реальный сетевой запуск проверяется отдельно, не подменяется fixture.
