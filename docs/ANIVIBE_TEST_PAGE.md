# Отдельная проверка AniVibe

`/player-test-anivibe/` — noindex-страница ручной проверки единственного постоянного iframe, предоставленного пользователем из партнёрского кабинета AniRezik: Shikimori 52299, серия 1. Источник — точная ссылка в `src/data/anivibe-embeds.json`, без генерации URL других тайтлов.

Iframe создаётся только после «Запустить тест», с исходными width/height/frameborder/allow/allowfullscreen/referrerpolicy. Успешное создание iframe не обозначается как успешное воспроизведение. Никаких API-запросов, ключей, обходов, изменения рекламы или внешних селекторов нет. В основной AnimePlayer провайдер не включается; enabled=false сохранён. AniLiberty не изменяется.

Проверка вручную: нажать кнопку, запустить первую серию внутри iframe, убедиться в движущемся изображении, звуке и увеличении времени за 20–30 секунд; повторить на телефоне. При ошибке записать устройство, браузер и текст сообщения. Возврат к основной странице использует paths.ts и работает с GitHub Pages base `/anirezik`.

Публикация этого теста не является выпуском AniVibe как рабочего основного источника. Версия приложения остаётся 0.4.1.
