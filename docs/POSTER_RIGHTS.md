# Постеры: подтверждения и ограничения, 0.3.3

## Действующий публичный источник: TVmaze, 24 октября 2026

Бесплатный источник без регистрации/ключа найден и подключён для **20 сериалов / 40 точных URL medium+original**. Это ограниченный набор, не разрешение на все 28 757 URL Shikimori.

Первичные основания:

- [Официальная документация, Images](https://www.tvmaze.com/api#images) прямо разрешает hotlink на CDN и бессрочный кеш: содержимое URL неизменно, смена изображения создаёт новый URL. Мы сохраняем только URL, не файлы; HTTP-кеш браузера определяется заголовками CDN.
- [Licensing](https://www.tvmaze.com/api#licensing) разрешает публичное использование API по [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/): указание TVmaze, ссылка на источник/лицензию, обозначение изменений, ShareAlike. Ключ/платный тариф не требуются.
- [Image Copyright Attribution](https://www.tvmaze.com/threads/56/image-copyright-attribution): участники **david** и **Jan** помечены Admin; ответ касается именно постеров API и объясняет атрибуцию TVmaze со ссылкой. Это первичное разъяснение поставщика, а не мнение стороннего разработчика.
- [Copyright Policy](https://www.tvmaze.com/site/copyright) принимает распространяемые пресс-материалы, свободно лицензированные/собственные материалы. TVmaze не становится владельцем персонажей и всех изображений. Мы используем явные условия API/доставки, не делаем вывода о переходе исключительных прав.

Охват зафиксирован в `image-sources.json`: только `https://static.tvmaze.com`, scope `urls`, 20 ручных соответствий в `image-rights.json`. Проверены Animation/Japanese, название и премьера; отброшены игровые адаптации Cowboy Bebop/One Piece и одноимённые продолжения. Источник учитывает сериал целиком, его текущий постер может представлять более поздний сезон. На Shikimori ID остальных сезонов такой постер автоматически не размножается.

Атрибуция/ссылки/лицензия размещены в Footer и About, индивидуальные страницы TVmaze и оригиналы перечислены в About. Открытый `poster-credits.json` отдаёт отдельную коллекцию ссылок и сопоставлений на тех же условиях CC BY-SA 4.0. В файлах изображений изменений нет; CSS кадрирует карточки, размывает/затемняет фон. Материалы TVmaze и изменения их представления распространяются на тех же условиях. Не заявляется лицензирование всей базы Shikimori или авторство TVmaze на исходный арт. Source API не вызывается при загрузке сайта, прокрутке или сборке.

Проверенные сериал-постеры: Cowboy Bebop, Naruto, One Piece, Bleach, Death Note, Naruto Shippuden, Fullmetal Alchemist: Brotherhood, Steins;Gate, Attack on Titan, Haikyuu!!, One-Punch Man, Re:ZERO, My Hero Academia, Violet Evergarden, Demon Slayer, Jujutsu Kaisen, Chainsaw Man, Spy×Family, Solo Leveling, Frieren. Покрытие ограничено этими записями; не заявляется полный каталог TVmaze, исключительная лицензия или отсутствие любых возможных требований третьих лиц. Отзыв реестра немедленно восстанавливает сохранённые AI-иллюстрации/заглушки в следующей сборке. Права на Shikimori этим не подтверждены.

Повторная проверка [Shikimori terms](https://shikimori.io/terms), [for rights holders](https://shikimori.io/for_right_holders) не дала общего разрешения на embedding/cache. Сообщение владельца о согласии администрации не заменено выдуманным evidence. Для включения Shikimori всё ещё нужен сам ответ источника с отправителем, датой и объёмом прав. Старые исследования ниже сохранены как история.

## История исследования 0.3.1

В 0.3.1 пользователь отдельно разрешил локальную экспериментальную проверку настоящих URL. Она дала 30/30 декодирований и не считается разрешением на публичное встраивание. Production/CI игнорируют локальный переключатель, реестр Shikimori остаётся unknown. [Механизм и необходимые подтверждения](REMOTE_POSTERS.md).

Проверка 24 октября 2026. В 0.3.0 пользователь подтвердил отсутствие разрешений; сторонние изображения не активируются. Реализован отдельный RemotePoster/backdrop-тракт, его 30 собственных HTTPS fixtures не считаются настоящими аниме-постерами. HTTP 200, CORS и URL подтверждают доставку файла. Условия API и права на конкретное изображение — разные вопросы. Это журнал подтверждений/неизвестного, не универсальное юридическое разрешение.

## Shikimori

Проверены [API docs](https://shikimori.io/api/doc), [соглашение](https://shikimori.io/terms) (дата на странице 29.10.2012), [страница для правообладателей](https://shikimori.io/for_right_holders) (01.04.2017). Поиск обсуждений API/постеров не дал подтверждённой универсальной лицензии администрации: сообщения сторонних разработчиков не считаются разрешением.

Соглашение указывает стороннее происхождение материалов и ограничения прав третьих лиц. Страница правообладателей описывает удаление спорных материалов, не выдачу лицензий. Ни один документ не подтверждает право AniRezik публиковать все постеры.

| Вопрос | Результат |
| --- | --- |
| Показ в стороннем каталоге | Универсальное разрешение не найдено. Полей poster.mainUrl/originalUrl недостаточно. |
| Hotlink с CDN | Техническая доставка проверялась в 0.2.1; условия embedding, трафика и Referer не подтверждены. |
| Кеш, свой CDN, изменение размеров | Лицензия/срок хранения не подтверждены. Массово не скачиваем и в проекте не кешируем. |
| Атрибуция | Специальные требования к повторной публикации постеров в проверенных документах не установлены. Подпись «Shikimori» не создаёт разрешения. |
| Коммерция | Нужны условия администрации на API/инфраструктуру и разрешение обладателя прав на арт: территория, срок, реклама/монетизация, хранение, производные размеры. Администрация должна подтвердить, какие права вправе передавать сама. |

Статус неизвестен, а не «технически сломано» или «точно запрещено». Настоящие постеры Shikimori не включены. [Конкретный запрос администрации](SHIKIMORI_REQUEST.md) подготовлен, не отправлен.

## Другие официальные API

**TMDB** прямо описывает использование изображений API в приложениях и бесплатное некоммерческое использование с атрибуцией. [FAQ](https://developer.themoviedb.org/docs/faq) требует логотип и уведомление об отсутствии одобрения в About/Credits; TMDB не заявляет владение всеми изображениями. [API terms](https://www.themoviedb.org/api-terms-of-use?language=en-CA), разделы 1–4: запрещают кеш свыше 6 месяцев и нарушение прав третьих лиц, требуют отдельный письменный договор для коммерческого использования. [Image basics](https://developer.themoviedb.org/docs/image-basics) описывает URL доставки, не отдельную лицензию каждого постера. Кандидат после регистрации ключа, принятия актуальных условий, сопоставления Shikimori↔TMDB и проверки прав/атрибуции конкретных изображений. Ключа/договорённости/сопоставления у проекта нет; включение всей базы этим исследованием не обосновано.

**AniList**: [официальные условия](https://docs.anilist.co/guide/terms-of-use) запрещают накопление данных и использование API в конкурирующих некомплементарных anime/manga list/tracker сервисах. Это не замена постеров для статического AniRezik без отдельного согласования. Наличие coverImage и бесплатного API не снимает ограничения и не подтверждает права на постеры.

Студия/лицензиат может предоставить press kit или письменное разрешение на отдельный арт. Применяется лицензия конкретного набора файлов; открытый сайт не разрешает массовую перепубликацию.

## Подключение после подтверждения

Сохранить документ/переписку, дату, правообладателя, точный источник и способы использования. В `image-rights.json` у конкретного Shikimori ID добавить разрешённый URL, атрибуцию, `permission-granted` и evidence со ссылкой на подтверждение и условиями hotlink/cache/commercial. Ограничения срока/территории/монетизации фиксировать и проверять перед сменой режима сайта. `unknown` не активируется. Сохранены 16 подписанных AI-иллюстраций: это не настоящие постеры и не подтверждение коммерческих прав на персонажей. Остальные — нейтральные заглушки; тысячи замен не генерируются.

Проверка широких источников: официальный [TMDB TV images endpoint](https://developer.themoviedb.org/reference/tv-series-images) отдельно возвращает backdrops/posters/logos; [image basics](https://developer.themoviedb.org/docs/image-basics) описывает URL через configuration/base_url/file_size/file_path. То есть широкие файлы технически предусмотрены, но API требует credentials и условий использования. Без аккаунта/ключа и подтверждённых прав проекта реальные backdrops не получались и не включались; документация метода не считается разрешением на любой файл.
