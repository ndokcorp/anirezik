# Постеры AniRezik 0.3.3

## Результат проверки условий

24.10.2026 повторно прочитаны [условия Shikimori](https://shikimori.io/terms), [страница правообладателям](https://shikimori.io/for_right_holders), документация и существующие реестры проекта. В опубликованных страницах не найдено явного общего разрешения на стороннее публичное отображение всех poster.mainUrl/originalUrl, hotlinking и браузерный кеш. Это **не утверждение о запрете** и не техническая ошибка CDN.

Владелец сообщил в этом задании о согласии Shikimori на сотрудничество и использование постеров по URL. Первичный ответ, его автор/роль, дата и ссылка пока не предоставлены. Эти слова не подменены вымышленным письмом администрации: реестр отмечает awaiting-primary-message, evidence пуст, status unknown и scope none. Для активации нужен текст либо ссылка на фактический ответ, позволяющий установить публичное использование именно в AniRezik, CDN, обычный браузерный кеш, атрибуцию и охваченные произведения/файлы. Не требуется выдумывать отдельный договор, если все необходимые условия уже содержатся в переписке. Личные данные и секреты переписки публиковать не нужно.

Текущий сайт: https://ndokcorp.github.io/anirezik/; репозиторий: https://github.com/ndokcorp/anirezik. Подготовленный [запрос администрации](SHIKIMORI_REQUEST.md) не отправлялся.

## Что изменено технически

Существующие image-policy/image-service/RemotePoster/IntersectionObserver сохранены. Постеры появились также в связанных сезонах: компактные 48×72 миниатюры в прежних строках, lazy/async/cover/фиксированные размеры. Статические страницы используют общий Poster и разрешённые данные сборки; универсальная страница получает пакет только у экрана. Подпись источника/AI остаётся явной, заглушка и отказ CDN обрабатываются общим кодом. Доступное имя ссылки осталось названием тайтла, прежние маршруты сохранены.

Footer теперь учитывает фактически разрешённые постеры либо локальный эксперимент. Он не заявляет отсутствие постеров после будущего подтверждённого включения и не представляет локальный эксперимент публичной лицензией. Сводные количества вычисляются один раз при сборке, полный каталог не добавляется в HTML.

Реестр по-прежнему включает HTTPS origins, evidence, область all/ids/точных URLs, срок, hotlinking, кеш и атрибуцию. После внесения действительного подтверждения следующая обычная production-сборка автоматически публикует только охваченные URL во всех существующих разделах. Для карточек mainUrl, для подробностей originalUrl; отсутствующий вариант заменяет другой. Разрешённый широкий арт сохраняется, иначе compact poster используется для blur/градиента. Прокси, подмены заголовков, скачивание тысяч файлов, новый каталог и новый дизайн не добавлены.

## Проверки

`npm run test:posters:live`: 30 настоящих изображений из разрешённого локального экспериментального режима; выборка теперь явно включает ID **1, 5, 59193**. Повтор, кеш и медленная сеть проверяются отдельно.

`npm run test:posters:surfaces`: новый проверяющий скрипт реального UI в Chromium/Firefox/WebKit. Он использует **разрешённые системой URL**, не внедряет в production неизвестные исходные URL. Проверяет три требуемых ID на desktop/mobile, связанные сезоны, избранное, каталог, быструю смену запроса, глобальный поиск, reload, декодирование и отказ CDN. Если production-реестр не разрешает нужные ID, скрипт завершается с ошибкой и объяснением; успешная сборка не подменяет загрузку постеров.

По умолчанию скрипт пробует все три движка. На данной Windows Firefox снова не запускается (spawn UNKNOWN) — это явно отражено в [результате](research/poster-surfaces-0.3.3.json), а не скрыто как успешная проверка. Для отдельного доступного движка можно явно задать ANIREZIK_TEST_BROWSERS=chromium либо webkit. Все browser-проекты обычного npm test сохранены; CI выполняет Firefox на Ubuntu и WebKit на macOS.

Обычные воспроизводимые тесты production используют собственные SVG fixtures, не свидетельства реального разрешения и не сторонние постеры. Добавлены тесты ID 1/5/59193, связанных постеров, CDN fallback, мобильных размеров и сохранности прежних доступных имён ссылок. Реальная CDN-проверка остаётся отдельным отчётом. [30 изображений](research/remote-posters-local.json), [реальный UI](research/poster-surfaces-0.3.3.json).
