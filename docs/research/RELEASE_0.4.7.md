# AniRezik 0.4.7

## Интерфейс

История со значком часов — в правом верхнем углу телефона перед меню. В нижней панели остаются Главная, Каталог, Поиск, Коллекция, Войти. Настройки качества/скорости компактнее (до 228 px), раскрытие списка не увеличивает высоту панели. Подпись: «Авто-Переключение серий». Красная кнопка по центру при паузе появляется/исчезает за 160 ms; серия/озвучка стартового экрана после запуска скрыты. Видео всегда contain, без увеличения при паузе. На горизонтальном телефоне колонка озвучек — 168–210 px.

## Kodik: фактическое покрытие

26.10.2026 пользователь сообщил о согласии партнёра на API-запросы/публикацию и попросил **подготовить всё, а расширение включить после скрина переписки**. Скрин условий для нового токена ещё не предоставлен. Его значение не добавлялось в файлы, GitHub, клиент, отчёты или логи; реальные API-запросы с ним не выполнялись. Существующее основание iframe 39535 сохранено в [KODIK_PERMISSION](../rights/KODIK_PERMISSION.md).

Официальная [страница Kodik](https://kodikplayer.com/) направляет владельцев сайтов в поддержку, указав сайт, и не публикует лимиты партнёрского API/кеша. [AnimeParsers](https://github.com/YaNesyTortiK/AnimeParsers/blob/main/KODIK_API.md) прямо называет документацию неофициальной; [Rust SDK](https://docs.rs/kodik-api/latest/kodik_api/index.html) — технический ориентир, не договор. Извлечение чужих токенов не используется.

## Подготовленный путь активации

Переиспользованы клиент/кеш 0.4.5: точные Shikimori ID, год, формат, оригинальное название и контейнер сезона. Переводы voice/subtitles и перечисленные episode URLs отдельные; URL/hash не угадываются. Неоднозначность/неподтверждённый origin исключают источник. blockedCountries сохраняются и фильтруются при известном регионе; неизменённый iframe контролирует фактическую географию, рекламу и доступ.

`npm run kodik:plan` — офлайн-план. После подтверждения доступа малая диагностическая пачка: `npm run kodik:sync -- --ids=39535,52299,58567,52991,32281`. Без флагов доступа и KODIK_API_TOKEN команда прекращается до сети. После проверки реальных iframe: `npm run kodik:sync -- --catalog --publish-cache` продолжает общий каталог, без постоянного ограничения десятью ID. Astro build и браузер не вызывают Kodik API.

Курсор/дневная квота: `.cache/kodik-catalog/queue.json`, очищенные checkpoints — `entries/ID.json`. Очередь дедуплицирует ID, пропускает свежие записи, продолжает после ошибки и резервирует квоту до запроса. Смена approval revision не сбрасывает суточную квоту. Ошибка API оставляет публичный кеш прежним. Успешные not-found/needs-review заменяют старый источник; истёкшие записи недоступны браузеру и удаляются из следующего кандидата. Metadata без года/формата попадает в missingMetadataIds, без выдуманного соответствия.

`kodik-cache.yml` использует только Secret **KODIK_API_TOKEN**. Переменные **KODIK_API_ENABLED** и **KODIK_AUTO_UPDATE** не включались. Максимумы 200 запросов/запуск, 1000/сутки, интервал 1500 ms, TTL 24 ч и расписание 6 ч — предварительные технические значения: rateLimitsConfirmed=false запрещает их использование до сверки с условиями. Поддерживается до 5000 запросов/пачку с 45-минутным пределом; реальные настройки ограничиваются договором. Обход всего каталога требует scope=catalog.

Кандидат проходит pages.yml: офлайн-проверки, build, unit и три браузера. Только затем кеш сохраняется в main и публикуется тот же проверенный artifact. Ошибка сохраняет прежний сайт. Manifest передаёт удаления; EXPECTED_SHA запрещает публикацию поверх параллельного изменения main. Публикация snapshot и video cache одновременно запрещена.

## Следующее действие владельца

После подтверждения доступа workflow можно сначала запустить с publish=false: по умолчанию это 39535, 52299 и 32281. Он отдаёт очищенный probe-artifact для проверки, не меняя публичный кеш и сайт. Режим publish=true требует подтверждённого воспроизведения; пустые ids продолжают общий каталог. Расписание работает только при отдельном KODIK_AUTO_UPDATE=true.

Предоставить обещанный скрин условий Kodik для AniRezik: использование данного партнёрского токена для сайта/origin, поиск всего каталога, публичный кеш iframe, лимиты/TTL/расписание и допустимые iframe origins. Затем разрешённый ключ можно сохранить в KODIK_API_TOKEN, проверить малую пачку и воспроизведение, зафиксировать конфигурацию и включить очередь. Добавление Secret само по себе не включает каталог.
