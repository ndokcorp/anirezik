# Kodik: проверка после предоставления согласия

26.10.2026 получен скрин согласия на партнёрский токен AniRezik и публикацию кеша iframe. Основание: [KODIK_API_PERMISSION](../rights/KODIK_API_PERMISSION.md). SHA-256 приложенного изображения: `0C22964B95A10B3B0F54B5E9120569D8002ED95059862030BA79B2F10E0CB74A`. Численные лимиты тарифа на скрине не указаны.

Выполнен **один** серверный запрос существующим KodikApiClient: Shikimori **39535**, POST `/search` на `https://kodik-api.com`, token в query, with_episodes/with_seasons/with_material_data. Ответ: **HTTP 401**. Тело отказа и URL с ключом не сохранялись. После отказа очередь остановлена: 52299 и 32281 не запрашивались; массового импорта не было.

Адрес/метод/передача параметров сверены с первичным исходником [Client SDK](https://docs.rs/kodik-api/0.5.0/src/kodik_api/client.rs.html) и [Search SDK](https://docs.rs/kodik-api/0.5.0/src/kodik_api/search.rs.html): HTTPS kodik-api.com, POST /search, query token и payload. Исходники SDK не копировались. Причина отказа конкретного токена по одному HTTP-статусу не устанавливается; работоспособность ключа не подтверждена.

Проверены только имена GitHub Secrets: **KODIK_API_TOKEN отсутствует**. Значения Secrets не запрашивались. Предоставленный в этом чате токен передавался только через окружение дочернего Node-процесса, не через командную строку; он не записывался в исходники, локальные скрипты, GitHub, JSON-кеш или отчёты. Расширение и расписание Kodik остаются выключены.

## Необходимое действие

Сохранить действующий разрешённый для AniRezik токен в repository Secret **KODIK_API_TOKEN**: GitHub → ndokcorp/anirezik → Settings → Secrets and variables → Actions. Значение не присылать в чат. После этого можно продолжить малую серверную проверку, затем включать только реально найденные/проверенные релизы. Повторное согласие на уже подтверждённую скрином публикацию не запрашивается.
