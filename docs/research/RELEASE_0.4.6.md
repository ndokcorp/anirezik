# AniRezik 0.4.6 — результаты

Дата: 26.10.2026. Полного импорта Shikimori/AniLiberty не выполнялось. Сборка использует сохранённый снимок. [Машиночитаемые результаты](../diagnostics/RELEASE_0.4.6.json).

## Адреса

30 704 канонических `/anime/ID/`. 3 000 прежних подробных страниц перенесены под numeric ID; 27 704 остальных используют компактный bootstrap и общий обработчик данных. 30 720 legacy-документов покрывают `shikimori-ID` и 16 дополнительных редакционных slug. Все 3 000 ранее опубликованных страниц сохранены через перенаправления. Старый `anime/?id=` тоже работает.

GitHub Pages не даёт серверный 301 для этих файлов: legacy выполняет JS/meta replace, bootstrap не-SSR тайтла загружает общий `/anime/?id=ID`, который меняет отображаемый адрес на numeric через replaceState. Это дополнительная навигация только для не-SSR тайтлов. Прямое открытие/refresh работает, цикла нет; JS требуется для редких тайтлов, как и раньше. Стабильные localStorage-ключи не меняются. Canonical, OpenGraph и JSON-LD используют numeric URL; sitemap содержит только numeric anime URL. Не создаётся 30 тысяч полных копий оформления.

## Постеры

30 704 записей; 28 757 имеют main/original Shikimori URL, 1 947 — не имеют обоих. Структурно неправильных хостов, HTTP и относительных URL в исходных полях не найдено. Восемь существующих URL (1, 5, 36027, 39535, 52299, 52991, 54744, 59193) вернули 200 image/webp. Это выборка: остальные 28 749 удалённых URL не объявляются проверенными.

Один GraphQL запрос по восьми отсутствующим постерам вернул `poster:null` у всех восьми. Поэтому нет оснований придумывать main/original URL. Восстановлены три тайтла через разрешённый TVmaze: 98 → show 17155 My-HiME (2004), 143 → 18751 Kannazuki no Miko (2004), 149 → 14335 Loveless (2005). Сверены точное название/алиас, год, Japanese Animation TV; проверены и декодированы обе картинки каждого шоу (6 HTTP 200). Файлы не копировались в assets. Пары URL/атрибуция CC BY-SA 4.0 внесены в image-rights/image-sources и `/poster-credits.json`.

1 944 записи остаются без доступного разрешённого изображения в текущих данных. Это не результат проверки всех CDN на отказ. У всех прочих URL возможны будущие 403/404/429 и временные ошибки; клиент последовательно пробует main, original, подтверждённый резерв и заглушку без бесконечного цикла. CSP/mixed content в проверенных запросах не блокировали изображения. Никакие хосты не угадываются и не заменяются массово.

Для постепенного обновления метаданных уже существует `sync:anime -- --ids=...` с зарегистрированным SHIKIMORI_USER_AGENT, кешем и ограничениями ShikimoriApi. Дополнительный полный импорт не нужен.

## AniRezik Player / AniLiberty

Пять существующих seeds сохранены: 9253, 32281, 52299, 52991, 58567. Добавлены 21 (релиз 10290, 28 доступных серий), 269 (8452, 357), 5060 (8986, 25), 56733 (10306, 5). Это фактически полученные серии, а не обещание полного покрытия сериала. Итого 9 точных записей seed/index; on-demand поиск сохраняется для остальных тайтлов.

На всех четырёх новых тайтлах проверено настоящее воспроизведение в обычном Chromium: currentTime >1 сек., декодированные кадры 1280×720. Тест выполнялся с muted; прослушивание звука человеком не заявляется. Флаги geo/copyright у всех false, источники HTTPS принадлежат уже разрешённому cache-rfn.libria.fun. Исходные потоки не извлекались и не сохранялись.

Одна официальная страница каталога из 30 записей сообщает всего 1 873 релиза; это не число поддерживаемых аниме AniRezik. Найден ошибочный внешний ID: AniLiberty 10294 указывает Shikimori 136 (оригинал 1999), но сам релиз — Hunter x Hunter (2011). Отклонено как needs-review. Автоматическое разрешение теперь проверяет год/формат/явный сезон даже при официальном ID.

`npm run sync:aniliberty -- --max=3` — отдельно от build, одна страница по 30, до 3 полных релизов по умолчанию (допустимо 1–10). Кеш очереди/курсора и needs-review в `.cache/aniliberty-index`; компактный индекс без HLS URL — в src/data/aniliberty-index.json. При HTTP/429 ошибка останавливает запуск, прежний checked-in индекс сохраняется. Периодический массовый импорт и автоматическое расписание не включены. Дальнейшее расширение возможно малыми партиями с проверкой отчёта.

## Польза AnimeParsers и официальных API

| Возможность | Что использовано / ограничение |
|---|---|
| Shikimori GraphQL main/original/poster ID | Диагностика точных ID; действующие queries и mapper сохранены. null не заменяется вымышленным URL. |
| AniLiberty каталог, sorting, pagination, include/exclude | Отдельный ограниченный sync с курсором; Python-библиотека не перенесена. |
| Официальный shikimori.id / mal.id | Существующее точное сопоставление усилено проверкой противоречий. MAL используется только при отдельно известном MAL ID. |
| Episodes / HLS / обновления | Используются реальные episode.ordinal и разрешённые hls_480/720/1080; региональные флаги проверяются в браузере. |
| Метаданные озвучки | Технический providerId остаётся aniliberty, интерфейс — AniRezik; собственная озвучка подписана AniLibria, студии анимации не выдаются за озвучку. |
| Следующий эпизод и статус | Существующие nextEpisodeAt и actual availability сохранены, расписание не выдумывается. |
| Kodik shikimori_id, переводы, эпизоды, blocked countries | Уже подготовлено в отдельной 0.4.5; без собственного ключа новых Kodik релизов нет. 39535 сохранён. |
| Поиск | Существующий общий индекс и алиасы используются; изменён только href на numeric URL. |
| AnimeGO/JutSu и извлечение сторонних источников | Не внедрено: нет подтверждённых условий/доступа. Чужие токены и обходы не используются. |

Технические источники: [AnimeParsers README](https://github.com/YaNesyTortiK/AnimeParsers), [SHIKI_API](https://github.com/YaNesyTortiK/AnimeParsers/blob/main/SHIKI_API.md), [ANILIBERTY_API](https://github.com/YaNesyTortiK/AnimeParsers/blob/main/ANILIBERTY_API.md), [KODIK_API](https://github.com/YaNesyTortiK/AnimeParsers/blob/main/KODIK_API.md). Проверяемые первичные источники: [официальный AniLiberty Swagger](https://aniliberty.top/api/docs/v1), [его OpenAPI](https://aniliberty.top/storage/api/docs/v1?aniliberty-api-v1-docs.json), [GraphQL Shikimori](https://shikimori.io/api/graphql), [TVmaze API и изображения](https://www.tvmaze.com/api#images).

## Плеер и проверка

Звезда находится внутри карточки озвучки, текст заметнее, тип дорожки подписан отдельно. Fullscreen chrome скрывается вниз через 3 секунды воспроизведения без действий, движение возвращает его; на паузе и при открытых настройках управление остаётся. Заголовок внутри видео удалён; серия/озвучка показываются до первого запуска, после паузы остаётся только play. Play закреплён по центру; нижняя панель скрыта до запуска на ПК и телефонах. Начальный экран телефона не перегружен нижними контролами. Панель настроек и шестерёнка уменьшены.

Шкала использует одну формулу для preview и pointer seeking, с pointer capture; учтено округление координат WebKit. Клавиатура/касание остаются рабочими. Тесты проверяют точное совпадение preview/click, idle с имитацией fullscreen API, паузу и мобильные размеры. Нативный iPhone fullscreen имеет собственное управление браузера и не подменяется.

Проверка запуска `sync:aniliberty -- --max=1` на сохранённой очереди сделала один запрос, добавила 56733 и сохранила 29 оставшихся записей. Точное совпадение и настоящее воспроизведение 56733 затем подтверждены отдельно; не выполнялась серия повторных импортов. Размер проверенной сборки около 310.4 MiB вместо ~252 MiB до миграции — сохранён общий обработчик, нет 30 тысяч полных копий страниц.
