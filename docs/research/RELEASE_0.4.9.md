# 0.4.9 — AnimeGO: исследование, пилоты и границы доступа

Статус: **кандидат 0.4.9 с разрешёнными AnimeGO iframe**. После первоначального исследования пользователь предоставил разрешение AnimeGO. GUI, AniLiberty, Kodik, история и прогресс сохранены. Ниже первоначальные результаты исследования; актуальный результат подключения приведён в следующем разделе.

## Подключение после получения разрешения, 27.10.2026

Включён отдельный адаптер `animego-cvh`, использующий только точные ссылки AnimeGO `/cdn-iframe/`, возвращённые самим источником. Это не самостоятельный API CVH и не копирование чужих токенов. [Область разрешения](../rights/ANIMEGO_PERMISSION.md).

Из 30 ранее точно сопоставленных тайтлов у 23 обнаружен собственный bridge CVH; у семи такого iframe не получено. Проверены метаданные всех 256 доступных эпизодов; сохранены 688 сочетаний эпизод/перевод, 55 вариантов перевода суммарно по тайтлам. Полный список ID находится в `src/data/animego-index.json`. Для 22 аниме это резервный источник, для 41468 — первый настроенный плеер. Общее число тайтлов с настроенным провайдером увеличивается с 1588 до 1589. Это не обещание воспроизведения во всех регионах: ограничения проверяет официальный iframe.

Реальная проверка Chrome с origin `https://ndokcorp.github.io`, без подмены Referer и вмешательства в рекламу: 52299 — первая серия Amber, 6 секунд, 153 кадра 1920×1080; 41468 — первая серия AniLibria, 10 секунд, 269 кадров 1280×720; 32281 — фильм SHIZA Project, 10 секунд, 254 кадра 1280×720. Две последние проверки — viewport 390×844. Проверялось `video.player-media` после рекламы, а не рекламное видео или загрузка интерфейса. Исходные iframe не изменены.

Серии и переводы выбираются существующим MultiPlayer загрузкой полученной точной iframe-ссылки. Документированные обратные события CVH не установлены; адаптер не объявляет внутренний выбор подтверждённым по событию `load` и не синхронизирует вымышленные события. Отдельный секрет не нужен. Прямой Content API CVH по-прежнему требует собственного доступа, но для этого разрешённого bridge он не используется.

Сборка и браузер не обращаются к каталогу AnimeGO. Кеш формируется вручную серверным `python scripts/sync-animego-embeds.py --max=200` (Python + beautifulsoup4), максимум один запрос в 1,5 секунды, с возобновлением из `.cache/animego-embeds/progress.json`. `--refresh` обновляет ответы источника; не публикуйте частичную пачку при `stop`. Индекс заменяется только после завершения всех 30 проверенных кандидатов. Планового обновления AnimeGO пока нет. Расширение за пределы этих кандидатов требует новой точной сверки, а не генерации тысяч iframe. Автообновление AniLiberty сохранено.

[Полные результаты по 100 ID и пилотам](../diagnostics/ANIMEGO_0.4.9_RESEARCH.json). Никаких видеоссылок, ключей, чужих publisher IDs, постеров или описаний в этом JSON нет.

## AnimeParsers: что подтверждено кодом

Прочитаны весь AnimeGO-раздел README, синхронная реализация и соответствующие методы async-варианта. Лицензия библиотеки MIT не передаёт права на видео. Код не копировался.

`search` разбирает HTML; `anime_info` извлекает поля страницы; расписание использует жёстко заданный домен. `get_voices` читает кнопки AJAX-плеера, теряет отметку ошибки и выводит максимальный номер как число серий — это не проверка всех доступных эпизодов. AniBoom-методы разбирают параметры embed и запрашивают манифесты с подставленными заголовками. CVH-методы используют контекст издателя AnimeGO, выбирают переводы неточным сравнением и при одном сезоне заменяют запрошенный сезон. Эти приёмы не перенесены в AniRezik. Совпадение названий методов не доказывает текущий официальный контракт.

Источники: [README](https://github.com/YaNesyTortiK/AnimeParsers#animego-инструкция), [реализация](https://github.com/YaNesyTortiK/AnimeParsers/blob/main/src/anime_parsers_ru/parser_animego.py), [лицензия](https://github.com/YaNesyTortiK/AnimeParsers/blob/main/LICENSE).

## Разрешённый путь интеграции

Официальный сайт [CDN VideoHub](https://cdnvideohub.com/) связывает API с партнёрским подключением сайта, рекламой и личным кабинетом. Публичные общие условия: от 2 000 уникальных посетителей в сутки, доступ к статистике Метрики, их плеер первым. Индивидуальная переписка может уточнять условия, но её текст пока не получен.

[Официальная документация](https://public-api.cdnvideohub.com/api/v1/docs/index.html) действительно существует. В OpenAPI операции помечены BearerAuth; один запрос поиска без авторизации дал **401**. Подходящих переменных среды и Actions Secret по именам CVH/ANIMEGO/ANIBOOM не найдено; значения секретов не читались.

Документированы каталожные `titles`, `titles/search`, карточка, сезоны и эпизоды с курсорами; есть `updated_since`, restricted-marker и фильтр `mal_id`. **Фильтра shikimori_id нет.** MAL ID нельзя автоматически приравнивать к Shikimori ID. Схемы возвращают внешние IDs, метаданные, языки и студии переводов; готовые iframe/HLS/DASH URL в этом публичном контракте не документированы. Нужен выданный владельцу сайта код/дополнительная инструкция партнёра.

У AniBoom корневой публичный ответ содержит контакт `info@aniboom.one`; официального открытого контракта для стороннего сайта и разрешения на прямые потоки не установлено. Наличие параметров потока в чужой странице не заменяет такое разрешение.

Существующая машинная запись Kodik разрешает curated 39535. Чужие AnimeGO-ссылки не расширяют её автоматически. Рабочий Kodik 39535 и неработавший API-токен не затрагивались.

После доступа: AnimeGO остаётся источником каталоговых соответствий; VideoProvider регистрируется как конкретный CVH/AniBoom/Kodik. Подтверждённый Shikimori ID хранится основным, AnimeGO/CVH IDs — отдельными. Сезон, перевод и номера серий выбираются строго, без fuzzy/подмены сезона. Собственный секрет используется только сервером/Actions; в статический кеш допускаются лишь разрешённые метаданные и выданные iframe. Точные HTTPS origins и права проверяются существующим VideoRights. Пока нет выданного контракта, пустого адаптера, фиктивных кнопок и угаданных URL не добавлено.

## Собственный AniRezik Player

Технически текущий движок использует hls.js и native-HLS; DASH-движка нет. Подключение DASH URL как HLS не реализует DASH. Для прямого HLS нужны отдельное разрешение на собственный плеер, сохранение обязательной рекламы/атрибуции и настоящий CORS-доступ с `https://ndokcorp.github.io`. CORS metadata API/HEAD не доказывает CORS сегментов. Браузер не может выдавать свой Origin/Referer за другой сайт, а GitHub Pages не является серверным прокси.

Ни для AniBoom, ни для CVH право прямого воспроизведения и такой контракт не подтверждены. Поэтому сейчас **ни один из них не подключён непосредственно**. Если выданы только iframe, используется неизменённый официальный iframe; внутренние озвучки/серии не имитируются внешними селекторами без документированных команд и проверенных событий.

## Возобновление и дальнейший масштаб

`scripts/research/animego-audit.py` — рабочий metadata-only аудитор, не видеопровайдер. Нужен Python с beautifulsoup4 (только исследовательский инструмент, зависимости сайта не менялись). Он сохраняет snapshot robots/sitemap, курсор фактически через обработанные URL и результаты в `.cache/animego-research/progress.json`, уважает robots, делает минимум 1,5 с между запросами и 1–100 запросов за запуск. 403/429/challenge/ошибки останавливают запросы; неизвестное не превращается в not-found. Только подтверждённый 404 записывается как ошибка конкретной страницы. Новое исследование требует осознанного обновления входного snapshot, а не бесконтрольного фонового скрейпинга.

Пример: `python scripts/research/animego-audit.py --max-requests=15`. Повтор при завершённой очереди не делает запросов. Bootstrap при отсутствии файлов получает только публичные robots и sitemap в пределах того же бюджета. Выборка и промежуточный результат остаются после остановки процесса.

Для последующего полного расширения сначала нужен разрешённый канал: официальный партнёрский Content API, `updated_since` + курсоры, строгие trusted IDs/метаданные, restricted-marker, отзыв кеша, квоты менеджера и постоянный checkpoint по уже существующему образцу AniLiberty. Не требуется 30 704 отдельных поиска. До выдачи доступа такая синхронизация не запускается.

## Что необходимо от владельца

Получить у партнёра **комплект подключения именно AniRezik**: собственный доступ к API и официальный embed-код/контракт с одобренным origin `https://ndokcorp.github.io`, правилами кеширования, запросов, регионов, рекламы и прямого HLS (если он нужен). Текст переписки приложить без ключа; ключ при выдаче хранить как Actions Secret `CVH_API_TOKEN`, не в чате и не в браузере. Для 54744 — также точную страницу AnimeGO, если сервис её предоставит.

Пока этого комплекта нет, публиковать сторонние publisher IDs, угаданные bridges или обещать работающее видео нельзя. На основном сайте остаются прежние AniLiberty/Kodik; 0.4.9 не объявлена выпущенной с новыми плеерами.
