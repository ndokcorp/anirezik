## Контракт и запросы

Изучены целиком технический справочник [AnimeParsers](https://github.com/YaNesyTortiK/AnimeParsers/blob/main/ANILIBERTY_API.md) и актуальный официальный [OpenAPI](https://anilibria.top/storage/api/docs/v1?aniliberty-api-v1-docs.json). Чужой код не копировался. Используется существующий официальный API origin адаптера anilibria.top; aniliberty.top/api/docs/v1 вернул 403, прокси/обход не применялись.

Каталог возвращает data/meta.pagination, максимум 50 записей на страницу. include ограничивает метаданные; серии получаются официальным /anime/releases/list пакетами до 50 ID. /anime/releases/{id} остаётся для конкретного просмотра и подтверждения отсутствующей записи. GET/POST каталога, search и episode endpoint изучены; полный импорт не использует поиск по 30 тысячам Shikimori ID. Сортировки updated_at и фильтра updated_since в официальной схеме нет: лёгкие страницы перечитываются, stamp updated_at/fresh_at и TTL (6 часов ongoing, 24 остальных) определяют очередь подробностей.

Первый полный проход занял 78 HTTP-запросов синхронизации, включая три до исправления обработки неполных метаданных; два предварительных запроса схемы ответа не входят в эту сумму. Это не журнал запросов браузеров или документации. Собственное консервативное ограничение — 1,5 секунды между запросами, 100 запросов за запуск; это **не заявленный провайдером тариф/лимит**. 403 останавливает процесс, 429/5xx записывают Retry-After/backoff; ошибки сети/схемы сохраняют рабочий опубликованный индекс. Только подтверждённый 404 помечает релиз отозванным. Изменившийся во время пагинации каталог требует нового discovery-прохода, кеш доказательств сохраняется.

## Возобновление и публикация

`npm run sync:aniliberty -- --max-requests=100 --refresh` — новый лёгкий проход; без refresh продолжается checkpoint. `--publish-index` обновляет три локальных файла только после полного прохода. Указанный максимум — бюджет одного запуска, а не постоянный предел покрытия. Прогресс пишется после страницы и каждого обработанного релиза. Старые .cache-файлы v1 не удаляются.

Workflow `sync-aniliberty.yml` хранит валидируемый checkpoint в отдельной ветке `codex/aniliberty-sync-state` (state.json), а не в эвиктируемом Actions cache. В нём только метаданные, курсор, очередь и результаты проверок; HLS URL, постеров, описаний и ключей нет. Последовательные запуски продолжают бюджет; ошибки API не создают цикл немедленных повторов. Расписание каждые шесть часов включается переменной ANILIBERTY_SYNC_ENABLED=true. Секрет API не нужен.

Полный кандидат передаётся штатному Pages workflow: check → offline build → unit → Chromium/Firefox/WebKit → commit только трёх файлов индекса → deploy того же артефакта. Если проверки не прошли, прежний сайт и индекс сохраняются. Из feature-веток deploy запрещён. Старый статический mapping не должен оживать из localStorage после отзыва: предыдущие и спорные ID входят в excludedIds.

## Проверка видео

Отдельные live-тесты включаются только явно (`ANILIBERTY_LIVE=1`); семь категорий: Cowboy Bebop 1, New Saga 53397, Diamond no Ace ongoing 64505, Frieren 52991, фильм Your Name 32281, Tokyo Ghoul Jack OVA 30458, B: The Beginning ONA 32827. Проверяются исходный ID/флаги API, реально растущий currentTime, размеры и декодированные кадры, выбранная существующая серия. Выводится только безопасный playback.json без сетевых тел/HLS. На Windows WebKit сообщает отсутствие HLS-поддержки; проверка Safari-движка выполняется в macOS Actions. Фактический результат и ссылки на запуск добавляются после завершения проверки и deploy, не подменяются наличием URL.


Фактические проверки перед выпуском: [безопасный отчёт](../diagnostics/ANILIBERTY_PLAYBACK_0.4.8.json). Семь различных релизов декодированы локальным Chromium при 390×844; дополнительно Cowboy Bebop при 1440×900 (720p). Время >1 с, декодированные кадры >0. Из GitHub macOS оба движка получили официальный ID, 26 эпизодов и false/false, но currentTime остался 0; это **не** успех WebKit/видео в CI и не основание обходить ограничения. Новый origin cache.libria.fun зарегистрирован по двум официальным API-ответам, точный whitelist сохранён. Региональная доступность остаётся решением API/CDN. Интерфейс прошёл 73 проверки Chromium и 73 WebKit после обновления ожидания: статический индекс больше не делает поисковый запрос для 40748. Финальный Pages workflow дополнительно проверяет все три движка на macOS (Ubuntu apt mirror зависал); offline build остаётся на Linux.

В однозначно подключённых релизах — 20 387 эпизодов, четыре дробных. 22 955 — общий счёт эпизодов из всех подробных API-ответов, включая нуждающиеся в проверке; эти цифры не следует смешивать. Индекс — 139 908 байт JSON (около 17 КБ gzip), без HLS.
