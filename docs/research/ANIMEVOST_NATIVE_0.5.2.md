# AnimeVost → существующий AniRezik Player, 0.5.2

## Что реализовано

Отдельный AnimeVost VideoProvider использует прежний native AniRezik Player: play/pause, seek, громкость, качество, серии, fullscreen, сохранение прогресса и выбор провайдера. CSS и дизайн не менялись. AniLiberty, Kodik и 97 CVH-соответствий сохранены. [Права и пределы проверки отправителя](../rights/ANIMEVOST_PERMISSION.md). Скриншот и личные данные не публикуются.

Статический индекс содержит **2 803 соответствия**, а не 2 803 лично просмотренных видео. Resolver при открытии страницы запрашивает текущий playlist официального домена AnimeVost. Источник появляется только если API реально вернул эпизоды с точными разрешёнными номерами и валидными media URLs. Ошибка/пустой ответ/неизвестный origin не включают заглушку или iframe. API не даёт отдельного списка студий: показывается имя поставщика AnimeVost, поле dubbingStudio остаётся null. Не заявляем тысячи уникальных студий или альтернативных переводов.

Ссылки не записываются в статический JSON, HTML или localStorage. API не требует собственного ключа в проверенных запросах, CORS `*` позволяет работать с Pages без Python-backend. MP4 480/720 получены непосредственно из playlist; HLS/DASH здесь не наблюдались. Гарантированного срока жизни ссылок API не сообщает: краткий память-кеш — политика клиента, не срок действия поставщика. Для обновления устаревшей открытой сессии нужна новая загрузка страницы. Видео не проксируется.

## Каталог и масштабирование

Вместо 30 704 поисков использован `/v1/last?page=N&quantity=40`: последовательные запросы, checkpoint после каждой страницы, дедупликация release ID. Получено **3 602 уникальных релиза**; API сообщает 3 611, но страница 91 вернула лишь две записи. Очередь остановилась на проверке полноты, `complete=false`, расхождение 9 записей не скрыто. Ошибок 403/429 не было, ограничения не обходились. Не перезапускаем полный обход ради исправления счётчика.

Matcher сравнил существующий каталог из 30 704 Shikimori ID с уже полученными метаданными: точный нормализованный русский/оригинальный/альтернативный заголовок, точный год и формат. Цифры сезонов/частей не удаляются, несколько совпадающих Shikimori ID или несколько релизов для одного ID исключаются. **2 803 уникальных кандидата**, **799 остальных релизов требуют проверки** (нет точного соответствия/серий либо неоднозначность). Это не 799 доказанно отсутствующих аниме.

Из 2 803 ID **1 496 отсутствуют в прежнем объединении индексов** (1 664). Это потенциальное расширение доступности, а не 1 496 видеопроверок. Для индекса указано **45 535 номеров эпизодов по метаданным**; наличие каждого файла и все страны не проверены.

`python scripts/sync-animevost.py --max-pages 5` продолжает сохранённую очередь, не запускает параллельные потоки. Сохранённая ошибка блокирует сетевое продолжение; `--max-pages 0` повторяет только офлайн-matching. `--publish-exact` требует одобренного direct playback и записанного успешного cross-browser пилота, обновляет ID для ленивого resolver, не ставит playbackVerified всем записям. Неполный снимок не удаляет прежние связи. `--publish-reviewed` позволяет включить только четыре лично проверенных ID. Workflow `sync-animevost.yml` собирает кандидатов/сохраняет checkpoint как artifact/cache, ничего не публикует; расписание выключено до уточнения лимитов.

Добавление нового аниме не требует F12 или ручного iframe: обновление метаданных → точное соответствие → индекс ID → свежий playlist при открытии. Для неоднозначных сезонов требуется проверка, а не угадывание.

Итого: **4 аниме, 5 различных пар аниме/эпизод**, **4 варианта дорожки поставщика**, **1 первый реально проверенный плеер — 54744**. Доступность 50 эпизодов получена из API пилотных релизов, все 50 не просматривались. Дополнительных независимо названных студий подтверждено 0: API не предоставляет roster.

Видимая проверка выполнена в локальном обычном браузере, включая переключение AniLiberty/CVH → AnimeVost. Автотесты фактически декодировали видео, проверили время, перемотку, качество 480p и вторую серию. Chromium + mobile WebKit прошли локально. Локальный Firefox не запускался (`spawn UNKNOWN`), поэтому его проверка перенесена в CI; **Chromium / Firefox / mobile WebKit прошли [реальный CI-пилот](https://github.com/ndokcorp/anirezik/actions/runs/40543818722)**. Первые два упавших локальных теста ожидали кадр у остановленного после смены качества video; тест исправлен явным Play, код Player не переписывался.

## Проверки и выпуск

TypeScript/Astro, production build, профильные unit и штатный Pages workflow проверяются отдельно перед выпуском. Итоговый статус и production URL будут записаны после успешного deploy. До этого наличие ветки/локального build не означает публикацию. [Диагностика с точными границами](../diagnostics/ANIMEVOST_NATIVE_0.5.2.json).

Ограничения: расхождение upstream total; неизвестные договорные rate limits/expiry; каждый из 2 803 тайтлов, все эпизоды, страны и качества не проигрывались. Изменение CDN-origin блокирует поток до проверки, а не включает чужой host. API доступность и соответствие не подменяют видео-проверку; счётчики этих этапов разделены.
