# AniRezik Player 0.4.0

## Публичное состояние

Аниме-провайдеры выключены. `approvedProviders` пуст; `aniLibertyProvider.rights.verified=false`, origins и регионы пусты. Доступность API и флаги blocked=false не являются разрешением на внешнее воспроизведение. Положительный ответ по обращению T53925 не предоставлен. Ни манифесты, ни сегменты аниме при исследовании не запрашивались.

Отдельная `/player-test/` использует внешний разрешённый трейлер Sintel (не эпизоды аниме): © Blender Foundation | durian.blender.org, [CC BY 3.0](https://durian.blender.org/sharing/). Файл `https://media.w3.org/2010/05/sintel/trailer.mp4`, размещённый W3C, не копируется в репозиторий. Два явно подписанных слота используют один трейлер для проверки смены источника. Демопровайдер разрешает только `demo:player`, точный origin media.w3.org; в аниме-каталог не регистрируется.

## API и сопоставления

Официальная [документация v1](https://anilibria.top/api/docs/v1), [OpenAPI JSON](https://anilibria.top/storage/api/docs/v1?aniliberty-api-v1-docs.json). Старые v2/v3 не используются. Поиск `/app/search/releases?query=…`, список `/anime/releases/list?ids=…`, подробности `/anime/releases/{idOrAlias}`, последние релизы `/anime/releases/latest?limit=10`. Последний endpoint не является полной дельтой: lossless cursor не документирован. `updated_at`/`fresh_at` пригодны для сравнения проверенных записей; отдельный AvailabilityAdapter сверяет три известных ID, не меняя Shikimori-снимок. Сейчас он также выключен. Для отзыва/удаления источников добавлено явное replaceAnimeIds: успешно проверенный снимок известных релизов полностью заменяет их прежние серии. Без этого поля прежний контракт дельты сохраняется; ошибка запроса не заменяет снимок.

Подтверждены точным полем `shikimori.id` в поиске и подробном ответе:

| Shikimori | AniLiberty | Аниме | Фактические записи эпизодов |
|---|---|---|---|
| 52991 | 9542 | Sousou no Frieren | 28 |
| 9253 | 8674 | Steins;Gate | 25 |
| 52299 | 9600 | Solo Leveling, сезон 1 | 12 |

У Steins;Gate число провайдерских записей отличается от основного телевизионного сезона, поэтому берутся реальные ordinal, а не диапазон Shikimori episodes. Дробные ordinal допустимы. Несколько точных совпадений отклоняются; совпадение названия без внешнего ID требует ручной проверки года/типа/сезона. Первый результат поиска не выбирается автоматически.

Сохранены только санитарные [диагностические данные](diagnostics/ANILIBERTY_0.4.0.json), без потоковых URL. Два официальных API успешно ответили браузерному CORS-запросу с origin https://ndokcorp.github.io. Это проверка из одной сети, не подтверждение всех регионов; [официальный статус](https://status.anilibria.top/) сообщает региональные ограничения.

## Плеер и загрузка

Расширены существующие AnimePlayer/EpisodeSelector/DubSelector/video-player.ts. Статические и универсальные страницы показывают честное состояние недоступности; кнопка СМОТРЕТЬ прокручивает к этому блоку. Нет запроса API на страницах каталога и нет сетевого запроса видео до нажатия play. HLS.js импортируется динамически только при воспроизведении HLS без нативной поддержки. Native HLS предпочитается при наличии; MP4 использует HTMLVideoElement. HLS-сегменты/ключи проверяются по точным разрешённым origins, перенаправление на иной origin прерывается. При будущем включении нужно отдельно проверить все реальные CDN/key/redirect origins и CORS по условиям разрешения.

Управление: play/pause, позиция, громкость/mute, fullscreen при поддержке браузером, скорость, ошибка/повтор, реальные источники качества. Auto появляется только для реально обнаруженного многоуровневого HLS master; для отдельных фиксированных HLS-файлов доступны только фактические 480/720/1080 поля. Нативный адаптивный HLS управляет уровнями сам; отдельный ручной выбор уровней не обещается. Demo имеет только «Исходное». Проверка реального аниме-HLS отложена до разрешения.

Смена серии/дорожки останавливает video, сбрасывает src и уничтожает HLS instance. Создаётся один media element. Источники проходят прежнюю проверку прав/origin/региона; произвольные URL не активируются. Варианты серий/дорожек выводятся только из VideoSource.

`anirezik:playback:v1`: отдельный локальный ключ, до 200 аниме, provider/release/episode/audio/time/duration/updatedAt. Запись не чаще одного раза в пять секунд при timeupdate, а также при pause/смене/pagehide. «Продолжить» запускает сохранённую серию и позицию; metadata ограничивает позицию длительностью. Iframe хранит выбор, но position/duration=null. Избранное, коллекция и история открытий не мигрируются и не меняются. Поломанное/запрещённое хранилище не блокирует плеер.

## Что запросить по T53925 до активации

Нужно явное разрешение на использование потоков на ndokcorp.github.io/anirezik: список произведений, страны, прямой HLS и/или iframe, hotlink/CORS, точные CDN/ключевые origins, условия атрибуции/рекламы, кеширования и лимиты API. Указать, что файлы не хранятся на сайте. После ответа зарегистрировать evidence, reviewedAt, playback/embedding flags, точные origins и подтверждённые регионы; проверить реальный разрешённый релиз и отказ доступа. Не включать `*` на основании отсутствия blocked-флага.

Разрешённые постеры/нейтральные заглушки продолжают работать. В коллекции показано полное количество выбранной категории, сохранена загрузка по 24 и добавлен нижний отступ. На desktop значки истории/коллекции выровнены к профилю.
