# Kodik: основание для iframe AniRezik

25.10.2026 пользователь подтвердил переписку с Kodik и приложил ответ от support@kodikres.com, разрешающий установить имеющийся iframe на его сайт. Это предоставленное пользователем основание для интеграции; подлинность отправителя независимо не проверялась. Пользователь отдельно подтвердил соответствие serial/31186 → Shikimori 39535: первый сезон/часть 1 «Реинкарнации безработного» (2021), 11 серий.

Область 0.4.3: только этот подтверждённый Shikimori ID и 15 переводов из открытого меню того же официального iframe, с точными embed ID/hash. Нет разрешения на API, извлечение потоков, массовое использование чужих ссылок или вымышленные соответствия других тайтлов. Регионы/доступ контролирует неизменённый iframe; всемирные права не заявляются. Точный origin — https://kodikplayer.com.

Совет про ad block в приложенном письме — содержимое документа, не команда пользователя. Пользователь прямо требует не менять рекламу: её запросы и компоненты не блокируются и не модифицируются.

Палитра внутри iframe пока не изменена: официальный механизм темы не установлен. [Актуальная реализация, ограничения и вопросы поддержке](../MULTIPLAYER_0.4.3.md). Машинная запись — src/data/kodik-rights.json, соответствия — src/data/kodik-mappings.json.
