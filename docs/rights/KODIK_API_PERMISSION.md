# Kodik API: согласие для AniRezik

26.10.2026 пользователь предоставил скрин продолжения переписки с отображаемым отправителем support@kodikres.com. В ответе подтверждены использование партнёрского токена для AniRezik и публикация кеша iframe. Разрешены обычные запросы; ограничения отнесены к тарифу, численные значения на скрине отсутствуют. Это предоставленное владельцем сайта основание, а не независимая проверка отправителя или доказательство доступности конкретных релизов.

Первый этап — три последовательных Shikimori ID, не чаще одного запроса в 15 секунд, с остановкой при 401/403/429. Это собственный консервативный бюджет проверки, не объявленный лимит Kodik. Автоматический обход каталога и расписание не активируются этой записью. Публикуются только нормализованные точные соответствия с разрешёнными HTTPS iframe origins после проверки.

Токен в документ/репозиторий/клиент/отчёты не переносится. Совет о блокировке рекламы из верхней части скрина не является инструкцией пользователя: реклама, Origin/Referer, содержимое и защита iframe не меняются.
