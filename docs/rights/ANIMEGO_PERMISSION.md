# AnimeGO — разрешение пользователя и узкая область iframe

27.10.2026 (Asia/Tashkent) пользователь предоставил скрин письма от отображаемого отправителя AnimeGo <info@animego.me>, файл codex-clipboard-4e3fd495-418b-4714-b301-06726dc418c6.png, и прямо поручил установить плееры. Письмо разрешает установку с использованием данных AnimeParsers. Подлинность отправителя независимо не устанавливалась; исходный частный скрин не публикуется.

Разрешение применяется к реально возвращённым AnimeGO данным и собственным HTTPS iframe-обёрткам AnimeGO /cdn-iframe/. Конкретный видеопровайдер внутри — CVH, что сохраняется в названии источника и атрибуции. AnimeGO не объявляется владельцем видео. Точный разрешённый origin https://animego.me; сторонние standalone iframe AniBoom/Kodik этим новым адаптером не активируются. Прямые HLS/DASH, сторонний Content API и чужие pub/aggr не используются.

Проверка с реального https://ndokcorp.github.io origin выполнялась обычным браузером: неизменённый iframe AnimeGO открыл свой вложенный CVH-плеер; после штатной рекламы именно основное video.player-media достигло currentTime 6.09 с, 153 декодированных кадров, 1920×1080, duration 1422 с. Рекламные video.ad-module-player не засчитывались. Никакие рекламные запросы/компоненты не блокировались, Origin/Referer не подменялись. До завершения рекламы тест не объявлялся успешным.

Это разрешённая iframe-интеграция AnimeGO, а не доступ AniRezik к CVH Content API: тот отдельный API продолжает требовать собственный Bearer. Использование выданной сайтом iframe-обёртки не требует копирования чужих параметров API в код проекта. Региональные/правообладательские ограничения, реклама и внутреннее управление остаются у исходного iframe. Универсальная доступность по всем странам не заявляется.

Записи добавляются только после отдельного сопоставления Shikimori ID с названием/альтернативой/годом/форматом/сезоном страницы AnimeGO. AnimeGO ID и episode ID хранятся отдельно; embed URL берётся из ответа соответствующей серии целиком, а не конструируется из Shikimori ID. Номера доступных серий/переводы берутся из реально полученных ответов, не из максимального номера/планируемого количества. API-запросы сбора используют X-Requested-With как тип JSON-запроса, но не поддельные Origin/Referer.

Отзыв: verified=false в src/data/animego-rights.json отключает весь новый источник, не меняя AniLiberty и Kodik. Внутреннее видео iframe/реклама не изменяются и не перекрашиваются.
