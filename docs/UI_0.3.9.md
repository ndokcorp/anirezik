# Интерфейс 0.3.9

- Хронология: стрелки влево/вправо, disabled на границах, native touch/keyboard, reduced-motion. На desktop hover затемняет постер, слегка увеличивает и показывает красный круг с треугольником/свечением. Каталожные карточки используют прежний play overlay с затемнением.
- Порядок: связи предыстории/продолжения имеют приоритет над датой. Независимые побочные истории и спорные циклы сортируются по датам. Это доступные связи источника, не редакционно подтверждённый канон всех франшиз.
- Фильтры: native dialog, тип/статус/жанр/тема/студия/год/минимальная оценка/сортировка; озвучка явно недоступна (бета). Поиск в каталоге один. Старые адреса/параметры сохранены.
- Telegram/Discord: community.json содержит предоставленные владельцем адреса https://t.me/anirezik и https://discord.gg/Rv3eW3qNN5; значки — обычные внешние ссылки с noopener noreferrer. Новости — только реальные изменения сайта из site-updates.json, без фальшивой ленты внешних новостей.
- СМОТРЕТЬ — переход к секции плеера, рядом честное сообщение о недоступности просмотра; воспроизведение не имитируется.
- Длинные разрешённые описания: пять строк, развернуть/свернуть, retry при отказе. Прежние 23 ID, независимый JSON и атрибуция. Shikimori разрешил постеры; подтверждение на повторную публикацию описаний не предоставлено. Пример запроса: «Разрешаете ли вы AniRezik публично отображать тексты описаний аниме из вашего API, с указанием Shikimori и ссылкой на оригинал? Есть ли требования к атрибуции и ограничения по текстам?»
- Никаких повторных импортов каталога/массового скачивания картинок. Сборка остаётся offline, 30 704 записи, stable IDs, lazy/кеш/избранное сохранены.
