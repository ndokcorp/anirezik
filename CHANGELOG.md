# 0.3.2

- Адресный daily maintenance вместо популярного топа: новые/изменённые записи, два сезона и вращающаяся очередь активных ID, ограниченный бюджет и возобновление. Полный аудит с защитой уменьшения охвата; все 30 704 ID сохранены.
- catalog.json уменьшен на 24,6% без изменения полей/схемы; compact atomic writer и прежний backup.
- Подгрузка image-packages по видимости карточек, общая очередь/кеш, проверка повреждения, защита от устаревших ответов.
- Машинно проверяемые области прав all/ids/urls/none и срок. Публичный Shikimori выключен, локальный эксперимент сохранён.
- Reusable Pages pipeline: все проверки до metadata-only commit и deploy. Ежедневный запуск требует зарегистрированного приложения владельца; платные услуги/новый сервер не добавлены.
- Отдельный контракт будущих дельт серий/озвучек, без включения неразрешённых провайдеров.
- Новые тесты сохранности каталога, отказов/возобновления sync, областей прав, ленивых пакетов и гонок изображений; повторная проверка реальных постеров и мобильные измерения.

# История изменений

## 0.3.1 — 24 октября 2026

- Добавлен opt-in `npm run dev:posters`: настоящие постеры из сохранённых точных Shikimori mainUrl/originalUrl доступны только в локальном dev вне CI. Production игнорирует переключатель; проверка hostname ограничивает эксперимент loopback.
- Общий реестр `image-sources.json` позволяет после документального подтверждения условий включить источник для всего каталога. Сейчас статус unknown; индивидуальный `image-rights.json` сохранён, разрешения не выдуманы.
- Карточки используют компактный mainUrl, детали — originalUrl. Пакеты изображений по диапазонам ID загружаются только для нужных карточек/деталей, максимум три запроса одновременно; полный массив URL не передаётся браузеру.
- Реальная локальная браузерная проверка: 30/30 постеров разных категорий декодировались, 30 повторов обслужены кешем, API-запросов 0. Добавлены измерения медленного мобильного подключения, тесты политики production/CI, исходного качества, пакетов и отказов изображений.
- Создан публичный репозиторий ndokcorp/anirezik и выбран GitHub Actions как источник бесплатного Pages. Дизайн, assets, каталог и прежние маршруты сохранены.

## 0.3.0 — 24 октября 2026

- Импортирован весь обнаруженный набор публичного GraphQL: 30 704 уникальных аниме, все типы/статусы/годы, без рейтингового ограничения. Прямой и обратный списки ID совпали, отсутствующих связанных ID нет. Скрытые/удалённые данные не объявляются покрытыми.
- Добавлен полный импорт с кешем, промежуточным отчётом, обратной сверкой/восстановлением пропусков и атомарной публикацией. Первый запуск — 1230 последовательных запросов, повтор — 1230 пакетов из кеша без новых API-запросов. Улучшена устойчивость rename к временным Windows-блокировкам; прогресс вынесен из наблюдаемой папки src.
- Все прежние 3000 SEO-страниц сохранены; новые тайтлы используют `/anime/?id=ID` и отдельные локальные JSON. Нет десятков тысяч тяжёлых HTML и запросов к Shikimori при открытии страницы.
- Каталог выводит 24 карточки, избранное загружает только нужные пакеты. Полный каталог больше не находится в DOM. Фильтры/сортировка/миграция и неизвестные записи избранного сохранены.
- Компактный индекс со справочниками, gzip-файл и Web Worker загружаются по вводу/фильтру. Основной поток получает лишь результаты, загрузка/ошибка видимы. Исправлен ранний клик по старой выборке во время загрузки URL-фильтра.
- Добавлены RemotePoster, независимые poster/backdrop/source/attribution/license и единый обработчик однократного fallback. Hero корректно обрабатывает HTTPS и атрибуцию. Неизвестные права не активируют URL.
- Пользователь подтвердил отсутствие разрешений на сторонние постеры: реальные внешние постеры не подключены. 30 собственных HTTPS SVG fixtures проверяют декодирование/ошибки, не выдаются за настоящие постеры или лицензию CDN.
- Добавлены тесты полного импорта/возобновления/пропусков, компактного формата, ленивой загрузки, универсальных страниц/ошибок/избранного и 30 изображений. Ручной workflow получил режим полного обхода. Обновлены документация и измерения производительности.

## 0.2.2 — 24 октября 2026

- Каталог расширен с 1000 до 3000 уникальных аниме: 40 новых запросов и 25 пакетов из кеша. Все прежние страницы сохранены. Цель по умолчанию 3000, настраиваемый предел 5000; добавлена проверка целочисленной цели.
- Поиск использует заранее нормализованный индекс и приоритет точного названия/алиаса. Фильтры перемещают только отображаемые карточки; разрешение связанных ID и сборка рекомендаций ускорены.
- Главная ограничивает подборку фильмов шестью карточками; «Смотреть все» открывает отфильтрованный каталог, вместо вывода сотен фильмов на главной.
- Исправлена потеря раннего нажатия избранного: его запуск больше не ждёт скачивания поискового индекса. Кнопки активируются после установки обработчиков.
- Реальный fetch с HTTPS GitHub Pages проверен в Chromium/WebKit. CORS работает, но Chromium игнорирует User-Agent приложения; неподтверждённая глобальная интеграция не включена.
- Добавлены исследование прав Shikimori/TMDB/AniList, неотправленный запрос администрации и варианты бесплатного сервера с учётом сетей РФ; Cloudflare не обязателен.
- Добавлены проверки прерванного импорта/возобновления, сохранения прежних ID, поиска трёх тайтлов вне исходной тысячи, неполных деталей и избранного при отказе индекса. Проверки ширин разделены на самостоятельные сценарии без сокращения покрытия.
